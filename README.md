# LINEA — студия дизайна интерьера с автоматическим конвейером

Клиент вводит размеры, загружает фото и чертежи, выбирает стиль (или доверяет студии и отвечает на наводящие вопросы) — система автоматически выдаёт **папку дизайн-проекта**:

```
00-pasport/      паспорт проекта (объект, стиль, палитра, состав)
01-plany/        планы каждого помещения с расстановкой мебели
02-razvertki/    развертка КАЖДОЙ стены (проёмы, отделка, размеры)
03-potolki/      планы потолков со светом и нишами штор
04-koncept/      концепция и палитра каждого помещения
05-materialy/    спецификация чистовых материалов
06-smeta/        смета: работы, материалы, мебель, свет (HTML + CSV)
index.html       интерактивный просмотрщик папки для клиента
```

## Быстрый старт
```bash
# сгенерировать демо-проект (54 м², джапанди)
node engine/generate.js examples/demo-brief.json site/portfolio/demo

# открыть сайт — любой статический сервер из site/
python3 -m http.server 8095 --directory site
```

## Как устроено
- **Сайт** (`site/`) — премиальный лендинг + бриф-визард (5 шагов, наводящие вопросы) → `brief.json`
- **Движок** (`engine/`) — Node без зависимостей: планировка мебели по правилам эргономики, развертки стен, потолки, смета по 3 тарифам, 6 пресетов стилей
- **Мультиагентный конвейер** (`.claude/`) — бриф-аналитик → концепт-дизайнер → планировщик → чертёжник → сметчик → визуализатор → главный архитектор (QA). Команды: `/new-client`, `/regen`, `/qa-project`
