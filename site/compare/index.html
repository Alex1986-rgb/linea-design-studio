Пакеты альбома

Базовый и полный: чем отличаются

Базовый · 46 листов

  • Сводные планы квартиры: обмер, демонтаж, монтаж, мебель, двери
  • Электрика: розетки, свет, выключатели, схема включения, щит
  • Полы, отделка стен, тёплые полы, климат, сантехника
  • Развёртка каждой стены + план обозначения развёрток
  • Два разреза, четыре узла, лестница (если есть)
  • Титул с перечнем, паспорт, ведомость, спецификация, смета

Полный · 96 листов

  • Всё из базового
  • Плюс покомнатные листы: обмер, демонтаж, монтаж по каждому помещению
  • Плюс покомнатные планы полов, потолков и электрики
  • Плюс листы умного дома и слаботочки по помещениям
  • Нужен, когда работы ведут разные бригады по комнатам
  • Включается флагом --package=full
