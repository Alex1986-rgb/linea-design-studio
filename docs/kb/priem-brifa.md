# Приём брифа с сайта и запуск проекта (тестовый период)

## Как клиент присылает бриф
- Страница `brief.html`: первый шаг — рассказ голосом (кнопка 🎤, подсказки-темы загораются по ходу рассказа; из рассказа
  сами заполняются тип объекта, площадь, кто живёт, животные). Дальше короткие шаги: объект и помещения → план и фото →
  «что нравится» (галерея визуализаций студии ♥/✕ + свои фото и ссылки) → вопросы → контакты.
- Последний шаг: кнопка «Отправить бриф с файлами» собирает в браузере архив `LINEA-brif-<имя>-<дата>.zip`
  (brief.json, brief.txt, plan/, referensy/, referensy-galereya.txt). На телефоне открывается «Поделиться» → WhatsApp /
  Telegram на +7 925 733-86-40; на компьютере архив скачивается. Запасные пути: текст в WhatsApp, письмо, копия.
- Черновик хранится в браузере клиента (localStorage) — можно вернуться. Файлы браузер не хранит.
- Голос работает в Chrome, Edge, Яндекс Браузере, Safari (iOS 14.5+); где нет — подсказка про микрофон на клавиатуре.

## Что делаем мы
1. Сохранить архив, разложить: `node tools/brief-intake.js ~/Downloads/LINEA-brif-….zip` → `clients/<слаг>/` + README со сводкой.
2. В течение дня — подтвердить получение и задать недостающие вопросы одним сообщением (размеры, высоты, стояки, несущие).
3. Проект — в GOST-DRAFT (`~/projects/gost-draft`): данные по плану → `projects/<слаг>/gen-layout.py` → `layout.json` →
   `node tools/new-project.js`; образец — `projects/dom-331`. Стиль и палитра — по ♥ галереи и референсам клиента,
   из проверенных кодов `knowledge/styles/data`; у каждой комнаты свой акцент; сюжет у каждой картины (DC-28);
   кухня — с навесными шкафами, если клиент не просил иначе. Чего нет в брифе — допущение в реестре К-N, не выдумка.
4. Сборка → 0 блокеров, студия → 0 ошибок, визуализации по глине, критики (приёмщик + скептик) → PDF студии клиенту.
5. Правки клиента — голосом по листам (страница проекта: «🎤 Замечание к листу») → список замечаний по владельцам листов.
