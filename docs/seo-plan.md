# LINEA · SEO-план

## Семантическое ядро (кластеры)
1. **Коммерческий хвост** (приоритет): дизайн проект квартиры цена · заказать дизайн проект · дизайн проект за 48 часов · дизайн проект онлайн · дизайн проект недорого
2. **По типу объекта**: дизайн проект однокомнатной/двухкомнатной/трёхкомнатной квартиры · дизайн проект студии 25 м² · дизайн проект дома
3. **По стилю** (страницы-кластеры): дизайн интерьера джапанди · сканди · минимализм · неоклассика · лофт — каждая со своим демо-проектом
4. **Состав проекта** (информационные, перехват до покупки): что входит в дизайн проект · развертка стен что это · смета на ремонт квартиры пример · план потолка со светом
5. **ИИ-хвост** (растущий, низкая конкуренция): дизайн интерьера нейросеть · ИИ дизайн квартиры · дизайн проект искусственный интеллект

## Структура сайта (целевая)
```
/                    — главная (коммерческий хвост)
/brief.html          — конверсионная
/portfolio/<slug>/   — кейсы: «2-комн. 54 м² джапанди» (тип+метраж+стиль в title)
/styles/<style>.html — 6 страниц стилей с демо-папками   [бэклог]
/blog/*.html         — информационные статьи кластера 4   [бэклог]
```

## Контент-правила
- Кейс = страница: title «Дизайн-проект [тип] [м²] в стиле [стиль] за 48 часов», внутри — реальные листы из папки, цифры сметы, CTA на бриф.
- Каждый новый демо-прогон конвейера = новый кейс = новая SEO-страница. Конвейер производит контент для SEO сам.
- Перелинковка: стиль ↔ кейсы этого стиля ↔ бриф.

## AI-SEO (цитируемость в LLM)
- FAQ-блоки с прямыми ответами (сделано на главной)
- Страница «Что входит в дизайн-проект» со структурированным списком — кандидат в цитаты ИИ-поисковиков
- llms.txt с описанием услуги [бэклог]
