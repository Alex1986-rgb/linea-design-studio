# Команда LINEA: кто за что отвечает

Каждый специалист — отдельный агент (`.claude/agents/<имя>.md`) со своей ролью (`prompts/roles/<имя>.md`).
Каждый сдаёт **один файл** в `clients/<slug>/team/NN-<имя>.md` в общем формате
(Итог / Результат / Замечания / Допущения / Вопросы / Передача). Движок и листы правит только чертёжник.
Запуск всей команды — `/team <slug или brief.json>`, ведёт прораб.

## Кого можно пропустить
- Нет новых перегородок и потолков из ГКЛ → без 07.
- Нет плитки (редко) → без 08.
- Мебель только покупная → без 10.
- Тариф не premium → без 15.
- Участка нет → без 20; только участок → 00, 01, 20, 12, 13, 16.

## Конфликты
Прораб собирает раздел «Передача» каждого файла. Конфликт между разделами (розетка за шкафом, вывод на шве
плитки, закладная не там) возвращается владельцу раздела; максимум 2 круга, затем решение ГИПа.
