# Почта на домене дизайн-студия-квартир.рф (Beget)

Домен в записях DNS и в адресах писем — в punycode: `xn-----6kccjicviedfr1b2cbishm8w.xn--p1ai`.
Зачем это нужно: коды входа в кабинет, подпись договора кодом и уведомления о новом брифе уходят через `mail()`.
Без ящика на домене и записей SPF/DKIM/DMARC они попадают в спам или не доходят. Сейчас `mail_from` пустой,
`notify_enabled = false`.

## Текущее состояние DNS (02.11.2026, около 14:00 МСК)

Не удалось прочитать: DNS Beget не отвечает. DoH Google по домену возвращает `SERVFAIL`,
по `beget.com` — «No Reachable Authority». API Beget тоже не открывается: `api.beget.com` не резолвится.
Когда DNS вернётся, `python3 -I tools/ops/dns-mail-plan.py` напечатает текущие записи из публичного DNS и из API и соберёт план.

## 1. Ящики (панель Beget → «Почта»)

1. В разделе «Почта» выбрать домен дизайн-студия-квартир.рф (домен должен обслуживаться почтой Beget: MX на `mx1/mx2.beget.com`).
2. Создать два ящика:
   - `info@` — отправитель писем сайта (`mail_from`) и ящик для ответов клиентов;
   - `dmarc@` — сюда приходят отчёты DMARC (можно не создавать и указать `--rua=info@…`).
3. Пароли ящиков положить в менеджер паролей. В репозиторий и в config.php их не писать: `mail()` пароль не нужен.

## 2. Записи DNS

| Имя | Тип | Значение | Зачем |
|---|---|---|---|
| домен | MX | `10 mx1.beget.com.`, `20 mx2.beget.com.` | приём почты (если ещё не стоят) |
| домен | TXT | `v=spf1 redirect=beget.com` | SPF: письма с серверов Beget разрешены (рекомендация Beget) |
| `_dmarc` | TXT | `v=DMARC1; p=none; rua=mailto:dmarc@<домен>; adkim=r; aspf=r; pct=100` | DMARC в режиме наблюдения; через 2–4 недели чистых отчётов — `p=quarantine` |
| `<селектор>._domainkey` | TXT | ключ от поддержки Beget | DKIM-подпись |

**DKIM на Beget:** по их базе знаний подпись для `mail()` возможна только с выделенным IP (платная услуга),
а для отправки через SMTP DKIM включает поддержка по тикету. Варианты:
- (быстро) тикет в поддержку: «включите DKIM для домена xn-----6kccjicviedfr1b2cbishm8w.xn--p1ai», полученный TXT
  передать в `dns-mail-plan.py --dkim='…' --selector=<селектор>`. Если поддержка скажет, что для `mail()` нужен выделенный IP,
  решаем: покупаем IP или переводим отправку сайта на SMTP ящика `info@` (это правка `server/api/lib/notify.php`, отдельная задача);
- без DKIM DMARC всё равно проходит по SPF: `notify.php` отправляет с `-f<mail_from>`, обратный адрес на домене совпадает
  с отправителем. Для Gmail и Яндекса этого мало для уверенной доставки, поэтому DKIM нужен до первых клиентов.

## 3. Как применить (делает Александр, это изменение боевого DNS)

```bash
python3 -I tools/ops/dns-mail-plan.py                      # только чтение: текущие записи + файлы плана + команды
python3 -I tools/ops/dns-mail-plan.py --dkim='v=DKIM1; k=rsa; p=…' --selector=beget   # когда поддержка выдаст DKIM
```

Скрипт **ничего не меняет**. Он печатает готовые команды `python3 -I tools/beget-api.py dns/changeRecords "$(cat …json)"`.
`changeRecords` заменяет все записи типа целиком, поэтому в план переносятся текущие A-записи и прочие TXT
(подтверждения Яндекса и Google). Перед запуском сверить A-запись в плане с текущей. Откат — та же команда с прежними записями,
которые скрипт печатает в начале.

## 4. config.php на сервере (после ящика)

```php
'mail_from' => 'info@xn-----6kccjicviedfr1b2cbishm8w.xn--p1ai',
'notify_enabled' => true,
'notify_to' => '<почта Александра>',
```

## 5. Проверка доставки

1. Записи: `https://dns.google/resolve?name=_dmarc.xn-----6kccjicviedfr1b2cbishm8w.xn--p1ai&type=TXT` (и `type=TXT` для домена) —
   записи видны через 15–60 минут.
2. Письмо из веб-почты Beget с `info@` на адрес, который выдаёт mail-tester.com: оценка 9–10 из 10, SPF/DKIM/DMARC зелёные.
3. Письмо с `info@` на Gmail → «Показать оригинал»: `SPF: PASS`, `DKIM: PASS`, `DMARC: PASS`. То же в Яндекс Почте («Свойства письма»).
4. Код входа в кабинет — только на тестовом заказе (`?test=1`), не с боевых форм: проверить, что письмо пришло во «Входящие».
5. Через неделю — отчёты DMARC в `dmarc@`: нет ли чужих отправителей от имени домена. Чисто — меняем `p=none` на `p=quarantine`.
