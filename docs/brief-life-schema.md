# Схема `life` в brief.json (шаг «Жизнь в квартире»)

Необязательный шаг брифа на сайте (`site/brief.html` + `site/js/brief-life.js`, добавлен 08.11.2026). Каталог вопросов живёт в `site/js/brief-life.js` (массив `G`) — эта таблица из него выгружена; при правке каталога обновлять оба места. Старые брифы без `life` читаются как раньше.

## Форма

```json
"life": {
  "version": 1,
  "skipped": false,
  "answered": 29,
  "unknown": ["kitchen.hood", "tv.projector"],
  "household": { "people": "3", "kids": ["school"], "pets": ["cat"] },
  "tv": { "rooms": ["living", "bedroom"], "size": "65", "mount": "wall", "sound": ["soundbar", "inwall"], "projector": "unknown", "note": "своими словами" },
  "text": ["ТВ и звук: ТВ в комнатах — Гостиная, Спальня; …", "Не знаю — решит дизайнер: вытяжка, проектор"]
}
```

- Группа → вопрос → ответ. Вопрос с одним ответом — строка-ключ, с несколькими — массив ключей. Нет ключа — вопрос не отвечен.
- `"unknown"` — клиент выбрал «Не знаю — решит дизайнер» (у многовариантных — `["unknown"]`). Список таких вопросов вида `группа.вопрос` продублирован в `life.unknown`.
- `"none"` — «нет / не нужно» (у многовариантных исключает остальные ключи).
- `note` — свободная строка к группе (до 300 знаков).
- `skipped: true` — шаг пропущен кнопкой, ответов нет. `answered` — число отвеченных вопросов (с заметками групп).
- `text` — готовая русская выжимка (она же попадает в `brief.txt`); для разбора движком не нужна.
- Дополнительно `answers.household / pets / wfh / storage / kitchen / sport` заполняются из `life`, если клиент не написал их сам в рассказе, — прежние читатели брифа получают их без правок.

Приёмник `server/api/brief.php` хранит brief.json целиком, поле проходит без изменений; согласие на ПДн проверяется отдельно и от `life` не зависит.
