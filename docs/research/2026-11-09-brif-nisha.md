## 2. Матрица вопросов

Обозначения «как спрашивать»: ЧИП — один или несколько вариантов-кнопок; ЧИСЛО — число/степпер; ДА/НЕТ; ФОТО — загрузка фото; ТЕКСТ — короткое поле; ШКАЛА — ползунок/3–5 вариантов; СПИСОК — повторяемые строки (название + размеры).
Колонка «Что меняет» — лист/решение/позиция сметы. У каждого вопроса в продукте стоит выбор «не знаю — решит дизайнер» (отдельно отмечено только там, где иначе нельзя).
Столбец «Ист.» — номера из таблицы источников.

| 17 | Питомцы: лоток, миски, мойка лап, корм, поведение | Не «один пункт анкеты», а сценарий и материалы | 50, 51, 21 |
| 18 | Состав семьи через 5 лет: ребёнок, родители, продажа/сдача | Детская «на вырост» не нужна, нужны заделы | 52, 7, 42 |
| 19 | Что клиент уже купил/выбрал (плитка, сантехника, двери, кухня) | Размеры и поставка уже заданы; длинная поставка срывает график | 39, 36 |
| 20 | Когда и как будете жить во время ремонта; нужен ли контроль работ | «Ходите с линейкой»; въехали в недоделанное — «хвосты» навсегда | 35, 36, 33 |

Вопросы «о форме»: клиенты жалуются не только на отсутствие вопросов, но и на формальные анкеты — вроде «нужен ли гигиенический душ» вместо расспросов о жизни (#41). Значит, часть вопросов должна быть сценарной («опишите утро»), а техника выводится из ответов автоматически.

## 5. Приёмы UX анкет, которые стоит взять

Подтверждённые несколькими источниками [2+]:

1. Дробление на этапы, «от общего к частному»: сначала простое (состав, стиль), тяжёлое (бюджет, инженерия) позже. (#16, #56, #60, #12)
2. Каждый вопрос с причиной «зачем»: одна строка под вопросом («от этого зависит высота шкафов»). Это снижает сопротивление и повышает честность ответов. (#56, #12, #11)
3. Картинки вместо слов там, где решает вкус: образцы света, стилей, санузлов, покрытий; «нравится / не нравится» с подписью-чипом «что именно» (цвет, материал, свет, форма). (#56, #11, #10, #58)
4. Честный индикатор прогресса: «Шаг 3 из 9, примерно 4 минуты», не больше обещанного. Не показывать процент на тяжёлых хвостах. (#56, #57, #20)
5. Сохранение на каждый ответ + возврат по ссылке на тот же вопрос; черновик не теряется (у ReBox черновик в браузере). Загруженные файлы не требовать заново. (#1, #57, #59, #56)
6. Выбор глубины: «короткий вариант» и «подробный» (как «упрощённый формат» у POINT FORM); в Ivanna-Studio клиент сам выбирает роль («знаю чего хочу» / «общее представление» / «полностью полагаюсь»). (#4, #6, #20)

Приёмы из одного источника [1]; брать как гипотезы:

7. Три варианта ответа на любой вопрос: ответ / «не знаю — решит дизайнер» / «пока не актуально». Пропуск не считается ошибкой, в сводке попадает в блок «решает дизайнер». (#59 — отсутствие «не знаю» названо нарушением; #12 — неизвестное в отдельный список «уточнить»)
8. Условное ветвление: вопросы про ребёнка, питомца, пожилых показывать только если ответили «да» на первом шаге; счётчик «осталось» при этом уменьшается. (#56)
9. Подставлять ответы обратно: «У вас кот Барсик — где будет лоток?» (#56)
10. Первый вопрос — касание (чипы с картинками «вы живёте: один / вдвоём / с детьми / с животными»), без печатания. (#56)
11. Карточки с иконками вместо выпадающих списков, подсказка «i» на месте. (#58)
12. Хронологический сценарий вместо длинных списков: «Расскажите утро» с готовыми шаблонами ответа + «своё». (#17, #19)
13. Закрытые вопросы чередовать с 2–3 открытыми («что раздражает сейчас», «чего боитесь»). (#16, #1)
14. Контакты / телефон в конце, с объяснением, кто и когда использует. (#56)
15. Итоговая «сводка из 5–6 пунктов» после анкеты (с возможностью исправить) — аналог подписанного ТЗ: стиль, цели планировки, обязательное, запретное, сроки. (#9, #11)
16. Вопрос «чего опасаетесь» и «чего не хотите видеть» — как отдельный экран «анти-задача». (#1, #2, #19)
17. Сквозное предупреждение о длине раздела («самый длинный раздел — следующий; последний — две строки»). (#20)
18. Повторный мини-опрос после концепции («не сместились ли желания?»). (#23)

Чего избегать:
- Анкета-прейскурант вроде «нужен ли гигиенический душ» без вопросов о жизни (#41).
- Вопросы только про стиль-ярлык (#45).
- Прогресс-бар с процентами, когда впереди тяжёлые вопросы (#57).
- Обязательные поля для необязательного (аллергия, здоровье) — давать «не хочу уточнять».

## 6. Рекомендации для LINEA (кратко)

1. Сверить текущие 65 вопросов шага «Жизнь в квартире» с матрицей §2: вероятные пробелы — таблица «что подключаем» (постоянно/иногда), рост и рука по каждому жильцу, шум по комнатам, трасса и разрешение на кондиционер, закладные под поручни/кроватку, мойка лап, «что уже куплено», срок проживания, роль клиента в процессе.
2. Топ-20 из §3 сделать обязательным «ядром», остальное — необязательными модулями (дети, питомцы, пожилые, хобби, гости), открываемыми по первому экрану.
3. Каждому вопросу в коде брифа добавить поля: `why`, `affects` (лист/позиция сметы), `ask` (chip / number / yes-no / photo), `unknown_ok`. Это превращает §2 в справочник для разработки.
4. Сводка ответов клиенту в конце (§5 п. 15) и список «решает дизайнер» (§5 п. 7): устраняет претензию «не услышали».
5. Проверить цифры, взятые из одного источника [1]: «10–15 точек питания на кухне» (мастер из МК), размеры доступной среды (СП 59.13330, ориентир, не норма для частной квартиры), высоты розеток и выключателей для пожилых (разные источники дают 40–60 и 80–100 см). Перед включением в документы проекта сверить с нормами и каноном `docs/cad-canon.md`.

## 7. Ограничения разведки

- Форум ForumHouse отдаёт при поиске в основном фрагменты тем; цитируемые «пожалел после ремонта» взяты из Woman.ru, Sibmama, Mom.life, INMYROOM, а не из Forumhouse напрямую (прямой подтверждённой ветки с «чек-листом ошибок» не найдено).
- Дзен и Houzz-форумы читались через поисковые выдержки, часть материалов старше 2020 года (Woman.ru — 2015, Sibmama — без даты, Houzz — 2015–2019). Для вопросов о привычках это не критично, для материалов и техники — устарело.
- Источники #19 (Rodriguez Studio), #20 (Interior Anthology), #21, #22, #25 — американские, про частные дома; брали только структуру вопросов о жизни, не планировочные нормы.
- Цифры по эргономике для пожилых (#48) — маркетинговые тексты студий; использовать как ориентир.
- Статьи 2026 года от студий и сервисов частично SEO-тексты; ценность — в структуре вопросов, не в статистике. Ни одного исследования с метриками «сколько клиентов бросают анкету» в сфере дизайна интерьера не найдено: данные об отсеве взяты из смежных областей (KYC, формы заказов) и помечены [1].
