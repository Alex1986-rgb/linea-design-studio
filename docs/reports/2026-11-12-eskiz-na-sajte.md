## Как пройти путь утром (с боевого сайта)
1. Сайт → «Заказать» (бриф): загрузить план **картинкой** (JPG/PNG; PDF — сохранить страницу картинкой), заполнить, отправить.
   В вопросе «Хотите что-то перестроить» обязательно ответить — без ответа эскиз не согласовать.
2. Админка → «Эскиз по плану» → в списке эскиз «Заказ LN-…» (через минуту — черновик описания). Проверить по плану, какая комната где,
   поправить → «Подтвердить описание и сгенерировать». Через 7–10 минут — виды сверху и интерьеры (страница обновляется сама).
3. «Показать клиенту» → в кабинете клиента появляется эскиз (уведомление). Клиент пишет правки словами или жмёт «Согласовать».
4. После согласования — полный проект (движок GOST-DRAFT, альбом), оплата — ручной счёт, пока нет ЮKassa.

## Не сделано / ограничения
- Оплата онлайн — ждёт реквизитов и ЮKassa (бухгалтер).
- Полный проект из эскиза — вручную через движок; косые стены в движке — у агента (идёт проверка на сервере).
- План в PDF эскиз не берёт — нужен скрин/картинка.
- Описание комнат моделью — черновик; без проверки дизайнером не генерировать.
