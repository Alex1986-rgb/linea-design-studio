# Бриф: наводящие вопросы «Жизнь в квартире» (08.11.2026)

## Сделано
- Новый необязательный шаг между «Что нравится» и «Расскажите словами»: 11 раскрывающихся групп, 65 вопросов-чипов, у каждого «Не знаю — решит дизайнер», у каждой группы «Зачем спрашиваем» и поле «своими словами». Кнопка «Пропустить шаг».
  Группы (вопросов): кто живёт 6, кухня и техника 10, ТВ и звук 6, климат 7, балкон/лоджия 5, хранение 7, санузлы и стирка 7, работа из дома 5, свет и умный дом 5, безопасность 5, особые вещи 2.
- Лоджия: формулировка про присоединение осторожная (ЖК РФ, Постановление № 170, «проверим по вашему плану»).
- Ответы: `brief.json → life` (схема — `docs/brief-life-schema.md`, пример — `examples/life-brief.json`); выжимка идёт в `brief.txt`/сводку; `answers.household/pets/wfh/storage/kitchen/sport` дополняются из `life`, если клиент сам не писал. Черновик в браузере сохраняет шаг; старые черновики сдвигаются корректно.
- Сервер `server/api/brief.php` хранит brief.json целиком — поле проходит, проверка согласия не затронута (код сервера не менялся).
- Движок (gost-draft-svod, `tools/site-brief.js`): `life` → `object.life` проекта + записи реестра К-N (ответы к закладным; «не знаю» — отдельной записью). Без `life` или при пропуске результат побайтово прежний (сверено на `tests/fixtures/briefs/brief-v3.json`, расходится только siteSlug из имени папки). Самотест site-brief — зелёный.
