## 4. Выкладка на Beget: `tools/deploy-3d.sh` (пробный режим по умолчанию)

Образец — `tools/deploy-beget.sh`: одна SSH-сессия на `beget-en0`, при VPN обход через en0, партии до 40 МБ / 300 файлов с паузой 3 с, rsync `--files-from`, при обрыве повтор и `tar | ssh`, сверка размеров каждого файла, прозвон адреса.

Что делает:
1. Берёт готовую папку заказчика (локально `--src` или со SmartApe `--from-server <путь> --token <токен>`; со SmartApe только читает через `tar`).
2. Проверяет: нужные файлы (index, scene.enc, config.json, .htaccess, LICENSE), внутри нет `*.info.json` (в нём пароль), нет маркера `ZZTOKENZZ`, срок ещё не вышел, внешних адресов нет. Сборки с токеном `TEST…` не публикуются без `--allow-test`.
3. На каждый проект делает карточку для альбома: `tools/3d/card.mjs` → `qr.svg`, `card.json`, `card.html` (QR, ссылка, пароль, срок до даты по Москве). QR рисует `tools/3d/qr-svg.swift` средствами macOS (CoreImage), без зависимостей; декодирование контрольно прочитало ссылку верно. Карточка с паролем остаётся в `.deploy/3d/cards/<токен>/` (вне git), на сервер не едет.
4. Пароль и токен на проект создаёт `make-client-bundle.mjs` при сборке (токен 32 знака, пароль 6 знаков без похожих символов, свой на каждый проект, хранится в `<токен>.info.json` рядом с папкой); без пароля карточка не собирается.
5. Корень поддомена (один раз, если файлов нет): `.htaccess` (301 на https, без листинга, noindex) и `robots.txt` (Disallow).
6. После заливки: сверка размеров; прозвон `https://3d…/<токен>/`, `config.json`, `scene.enc`, закрытый `.htaccess`, `http` должен уводить на https.

Переменные: `LINEA_SSH_HOST` (beget-en0), `LINEA_3D_DOCROOT` (по умолчанию `3d-linea/public_html`), `LINEA_3D_HOST`, `SMARTAPE_HOST`, `BATCH_MB`, `BATCH_N`, `BATCH_PAUSE`, `BEGET_BIND`. Адрес в punycode считает сам: `3d.xn-----6kccjicviedfr1b2cbishm8w.xn--p1ai`.

Прогнанный пробный запуск (обе тестовые папки, 641 файл, 32,2 МБ, 3 партии): связь с Beget есть, каталога `~/3d-linea/public_html` ещё нет (предупреждение), на сервер ничего не отправлено. Проверено также, что `--go` без каталога останавливается сам. Сам `--go` не запускался.

**http вместо https.** Просмотрщик расшифровывает сцену через WebCrypto, он есть только на https и localhost. Раньше по http страница писала «Не удалось загрузить проект». Теперь показывает карточку «Страница открыта по небезопасному адресу (http)…» с кнопкой «Открыть по https» (ссылка меняет схему) и подсказкой про QR. Проверено имитацией (нет `crypto.subtle`, `isSecureContext=false`) на 1280×800 и 375×812: поля пароля нет, сообщение и кнопка есть (`mobile-http-message`). Плюс сервер сам уводит http на https (корневой `.htaccess`).

## Как выложить по «да» (порядок)

Нужно один раз: создать сайт-каталог на Beget и привязать поддомен `3d.дизайн-студия-квартир.рф` (через панель или `python3 -I tools/beget-api.py site/add …` / `site/linkDomain …`; это мутация аккаунта), дождаться SSL и подтверждения Госуслуг. Затем:

```
# 1. собрать боевую папку на SmartApe (токен и пароль генерируются сами), НЕ «TEST…»:
#    node scripts\client-viewer\make-client-bundle.mjs --scene <сцена.json> --out D:\client-3d-out --name "<название>" --address "<адрес>"
# 2. посмотреть план (ничего не меняется):
./tools/deploy-3d.sh --from-server D:/client-3d-out --token <токен> --dry-run
# 3. залить после «да»:
./tools/deploy-3d.sh --from-server D:/client-3d-out --token <токен> --go
```

Карточка (QR + пароль) — `.deploy/3d/cards/<токен>/card.html`; в альбом идёт она.
