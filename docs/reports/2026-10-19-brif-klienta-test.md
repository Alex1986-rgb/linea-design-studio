# Отчёт: бриф для тестового клиента и правки голосом — 19.10.2026

## Что сделано
1. **Бриф `brief.html` — «сначала голос»**: первый шаг — большая кнопка 🎤 (Web Speech API, ru-RU), живой текст, подсказки
   «о чём рассказать» (9 тем загораются по ходу рассказа), пример рассказа. Из рассказа сами заполняются тип объекта,
   площадь, кто живёт, животные. 🎤 есть и у текстовых полей остальных шагов. Где голоса нет — подсказка про микрофон клавиатуры.
2. Шаги: Рассказ → Объект и помещения (для дома — этажи, лестница, участок, этаж у помещения) → План и фото → Что нравится →
   Вопросы → Контакты → Готово. На телефоне — «Шаг N из 7» и полоса прогресса.
3. **Референсы**: галерея 25 визуализаций из 7 проектов студии (`site/assets/refs/`, фильтр по стилю, ♥ / ✕), блок
   «что можно прислать» с примерами, загрузка своих фото, ссылки, «любимые / нелюбимые цвета».
4. **Отправка с файлами без сервера**: архив ZIP собирается в браузере (brief.json, brief.txt, plan/, referensy/,
   referensy-galereya.txt; фото ужимаются до 1600 px). На телефоне — «Поделиться» в WhatsApp / Telegram, на компьютере —
   скачивание; запасные пути — текст в WhatsApp, письмо, копия. Архив проверен `unzip -t`.
5. Черновик сохраняется в браузере и восстанавливается («начать заново» — сброс).
6. **Правки к листам голосом** — `review.html?p=<проект>`: лист крупно с масштабом, нажатие на чертёж ставит метку,
   правка голосом или текстом, правка ко всему листу, листание листов; все правки одним сообщением (Поделиться /
   WhatsApp / письмо / копия) с номерами листов и координатами меток. Плитки листов на страницах проектов ведут сюда,
   на странице проекта кнопка «🎤 Проверить листы и надиктовать правки».
7. Приём: `node tools/brief-intake.js <архив.zip>` → `clients/<слаг>/` + README со сводкой; памятка `docs/kb/priem-brifa.md`.
8. На сайте 7 проектов нового формата (квартиры, ретро, дом 331). Старые демо (`portfolio/demo`, `dom-120`) пересобираются
   в новый формат агентами в GOST-DRAFT — подключу по готовности.
