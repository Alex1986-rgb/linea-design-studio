# Доделка сайта LINEA — итог прогона критиков и агентов (27.10.2026)

Запрос: «запусти критиков и агентов и доделай сайт, обрати внимание на замечание ранее».
Прогон: 4 критика (техника, практик-Андрей, путь клиента, Beget) → бэкенд, тексты, главная →
выкладка → перепроверка → второй круг правок → выкладка. Всё на техническом адресе
http://linea.aleks2si.beget.tech/ (закрыт от индекса). **Push не делался**, GitHub Pages — старая версия.

## Что сделано

1. **Замечание практика (Андрей, «конфета с плохой начинкой»).**
   - Визуализации — только сверенные с планом (статус из gost-draft `views-check.js`). Прихожая с «зеркалом Дали»,
     вид сверху modern-4k (8 стульев), гостиная и детская от 20.10 сняты. Фильм на главной — 11 подписанных кадров
     modern-4k (первый — кабинет). У остальных проектов вместо кадра — лист расстановки мебели.
   - Убраны обещания, которые альбомы не держат: «по ним строят», «всё, о чём спросит бригада», «визуализация каждой
     стены», «928 правил вместо нормоконтролёра», «специалисты движка». «Проверка по нормам» → «Автопроверка
     оформления» с оговоркой, что она не отвечает на вопрос «сможет ли прораб работать».
   - Развёртки, электрика, ведомость дверей, колерная карта помечены «перевыпуск после разбора практика готовится»;
     на 9 альбомах плашка «выпуск до разбора», снимется сама после перевыпуска.
   - Цифры сведены: названия по экспликации (дом 271 м², 147 м², квартиры 101 и 55 м²), 935 листов, диапазоны
     64–124 / 139–162; вместо «315 замечаний» — строка «стоп-ошибок / замечаний / вопросов к заказчику — лист 06».
   - Старые альбомы первой версии (demo, dom-120, 17 стр.) — noindex, плашка «Архив, не сверено», убраны из sitemap.
2. **«Не делать дизайн, пока не оплатят».** «Бесплатно / без предоплаты / 0 ₽» убраны со всего сайта и из разметки.
   Плашка: «Работа — после оплаты, цену называем до старта». Условия — из одного места (`TERMS` в
   `tools/site-shell.js`). Новые страницы: `oplata/`, `soglasie/`, черновик `oferta/` (noindex, реквизиты не выдуманы);
   `policy/` переписана по факту (Beget, ЮKassa, WhatsApp по выбору).
3. **Бриф в один клик.** PHP-приёмник `server/api/` → на сервере `api/`: бриф получает номер заказа LN-ГГММ-NNNN и
   страницу `order.html` со статусом «ждёт оплаты → оплачен → выдан». ЮKassa (API v3, сумма только из заказа,
   вебхуку не верим — перепроверка через API) готова, но выключена: режим **manual** («счёт пришлём»).
   Закрытая страница заказов `api/admin.php`. Данные вне веб-корня: `~/dizain-studiya-kvartir/linea-private/`.
   Обязательная галочка согласия на ПДн (форма и сервер).
4. **Безопасность.** ПДн и вход в admin.php — только по https: по http сервер отвечает 403, сайт сам уходит на
   запасной путь (архив в WhatsApp/почту). Фраза об отправке брифа зависит от адреса: «одной кнопкой» только там,
   где есть приёмник с https. Починен вход в admin.php на Beget (сессии файлами).
5. **Уборка сервера.** `--prune` не удаляет, а переносит лишнее в `~/dizain-studiya-kvartir/public_html_backup/20261026-201925/`
   (97 файлов: снятые визуализации и служебные `_rules/_card/_renders/_release`).

- **Оплату принять пока нельзя:** нет цен, реквизитов, магазина ЮKassa LINEA, оферта — черновик.
- **Нет https** у технического адреса → приём брифа одной кнопкой и admin.php заработают на домене с SSL.
  После SSL проверить признак https Beget (сейчас `X-Forwarded-Proto` можно подделать вручную).
- **GitHub Pages — старая версия** («бесплатно», «331 м²», нет `oplata/`); 7 коммитов не запушены.
- Перевыпуск 9 альбомов после разбора практика (gost-draft `tools/remote-build.sh` → `sync-gost-releases.sh`).

  подписана «из проектов студии», хотя кадры старые — поправить подпись.
