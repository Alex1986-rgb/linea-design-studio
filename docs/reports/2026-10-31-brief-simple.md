## Что сделано

### Бриф — 3 шага + отправка (`site/brief.html`, `site/js/brief.js`)
1. **План квартиры** — переключатель «Квартира / Дом», большая кнопка «Загрузить план» (фото, скан, PDF, DWG; перетаскивание),
   на телефоне — отдельная кнопка «Сфотографировать план» (камера сразу), превью загруженного; площадь — одно необязательное поле.
   «Нет плана?» — галочка «снимите размеры сами» (`object.needSurvey`) и 4 строки «как измерить рулеткой». Без плана и без галочки дальше не пускает, ошибка рядом.
2. **Что нравится** — «Загрузить свои картинки» или нажать на кадры галереи (9 кадров разных стилей + «Показать ещё»; нажатие = ♥, счётчик).
   Выбор стиля и ✕ «не нравится» из основного пути убраны.
3. **Расскажите словами** — одно поле, кнопка «🎤 Надиктовать» (Web Speech API, понятные ошибки микрофона сохранены), под полем чипы
   «Кто живёт / Что мешает сейчас / Что точно нужно / Бюджет / Сроки» — нажатие вставляет строку-заготовку, после заполнения чип получает ✓.
   «Добавить подробности (необязательно)»: помещения с размерами, высота потолков, состояние, адрес, стиль, класс материалов, ссылки.
4. **Куда прислать проект** — сразу сумма по площади (62 м² → 124 000 ₽), имя, телефон или e-mail, обязательная неотмеченная галочка
   согласия на ПДн, необязательная «можно показать в портфолио», «Что будет дальше» (3 пункта) и кнопка отправки.

Качество: прогресс «Шаг N из 3 / Последний шаг», кнопки ≥ 44 px, ошибки у полей (`role=alert`, `aria-invalid`, фокус на поле),
черновик в localStorage (try/catch; файлы браузер не хранит — об этом пишет), без внешних библиотек, `<label>` у всех полей,
фокус на заголовок шага при переходе, `aria-live` для шага. На телефоне заголовок страницы сжат, кнопки «← / Дальше» прилипают к низу.

**Формат заказа не менялся:** архив `brief.json + brief.txt + plan/* + referensy/* (+ referensy-galereya.txt)`, те же поля `collect()`.
Новое в brief.json: `meta.source = 'site-brief-simple'`, `meta.version = 3`, `object.needSurvey`, `answers.must`, `answers.budget`.
`answers.*` заполняются из рассказа (строки-заготовки + ключевые слова: животные, кухня, хранение, спорт, работа из дома) — их читает site-brief.js.
`rooms` — пустой массив, если клиент не открыл «подробности».
