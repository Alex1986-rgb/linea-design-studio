# Gap-анализ движка чертежей LINEA против базы знаний drawing-kb

Дата: 21.09.2026 · Только анализ, код не менялся.

**Эталоны:** `docs/drawing-kb/01-gost-grafika.md`, `02-sostav-listov.md` (16 типов листов),
`11-grafika-chertezhey.md` (§3 — что забрать в движок), `docs/team.md` (новые роли), `docs/cad-canon.md`.
**Что проверено:** `engine/generate.js` (5775 строк), выпуск `site/portfolio/demo/` (45 листов, пакет `base`),
`tools/audit-sheets.js`.

**Ход работы:** 1) прочитать базу знаний и канон → 2) снять реестр листов (`FLAT_SHEETS`, стр. 5398) и
`data-sheet`/`data-el`/масштаб каждого SVG демо → 3) пройти функции листов грепом и чтением →
4) сверить с 16 типами и §3 → 5) бэклог.

**Главный вывод.** Все 16 типов листов в альбоме есть, кроме отдельного листа раскладки плитки.
`audit-sheets.js` по демо зелёный (45/45, 0 нарушений). Но его правила проверяют только наличие блоков
(легенда, штамп, цепочка). Содержательных требований новой базы они не проверяют: цвет↔легенда, «Н=»,
В1/Т3/Т4/К1, стрелка старта плитки, номер помещения с площадью. Поэтому зелёный аудит пока не значит,
что альбом соответствует базе знаний. Самые заметные дыры:
- в брифе нет схемы перепланировки, поэтому листы демонтажа и монтажа по сути заглушки;
- на плане сантехники нет трубопроводов с маркировкой;
- у плиточника, мебельщика и отделочника нет своих листов.

## 4. Бэклог доработок

Сложность: **S** до 2 ч · **M** полдня–день · **L** 2–4 дня. После каждой правки: `node tools/regen-fixtures.js`,
посмотреть листы глазами, затем `--update`, перегенерировать демо и дом-120.
