# Схема брифа, третья редакция: `life` v2, `tech` v1 и `home` v2 (09.11.2026)

Необязательные шаги брифа на сайте идут **после** главного «Расскажите словами»:

1. План квартиры → 2. Что нравится → 3. Расскажите словами → **«Жизнь в квартире»** (`life`) → **«Двери, свет и электрика»** (`tech`) →
   **«Дом и ремонт»** (`home`) → Куда прислать проект (сводка, контакты, согласие). Единая шкала «Шаг N из 7»; три шага с вопросами необязательны.

Каталог вопросов — данные в `site/js/brief-life.js` (массивы `LIFE`, `TECH` и `HOME`). Таблицы ниже выгружает из него
`node tools/brief-schema-doc.js` (`--check` — только сверить). Первая редакция (`life` v1, 65 вопросов) описана в
`docs/brief-life-schema.md`; её ключи **не переименованы** — старые brief.json и черновики читаются как раньше.

## Поля вопроса в каталоге

| поле | смысл |
|---|---|
| `k` | ключ ответа в brief.json (`life.<группа>.<k>`) |
| `l` | формулировка для клиента |
| `s` | короткое имя для выжимки и реестра К-N |
| `why` | зачем спрашиваем — одна строка под вопросом |
| `aff` (affects) | что меняет в проекте (лист, позиция) |
| `ask` | тип ввода: `one` — один чип, `multi` — несколько, `num` — число, `text` — строка до 300 знаков |
| `core` | вопрос ядра (виден сразу); остальные — под «Ещё N вопросов» в группе |
| `if` | `{ q, not: [...] }` — вопрос скрыт и не считается, пока ответ на `q` из списка `not`; `{ q, only: [...] }` — вопрос виден, только когда ответ на `q` из списка `only` |
| `h` | подсказка (пример ответа или пояснение термина): раскрывается кнопкой «подсказка» под вопросом; в brief.json не попадает |
| `ic` | набор иконок вариантов (`door`, `closet`, `lamp`): варианты рисуются плитками с линейной иконкой |
| `legacy` | вопрос или группа заменены новым вопросом в шаге «Двери, свет и электрика»: в форме не показываются, но старые ответы читаются из черновика и пишутся в brief.json (таблицы ниже помечают их «устар.») |
| `ul` | своя подпись «не знаю» (например, «Пока не знаю — предложите» у бюджета) |
| unknown_ok | у каждого вопроса есть ответ `unknown` |

## Форма в brief.json

```json
"life": {
  "version": 2, "skipped": false, "answered": 31, "core": { "answered": 19, "total": 25 },
  "unknown": ["kitchen.hood", "climate.acOutdoor"],
  "household": { "people": "3", "kids": ["planned"], "pets": ["cat"], "height": 168, "hand": "left" },
  "taste": { "avoidColors": ["grey", "coldwhite"], "avoidMaterials": ["gloss"], "words": "холодно, офис" },
  "text": ["Кто живёт: живут — 3; …", "Не знаю — решит дизайнер: вытяжка, наружные блоки"],
  "sum": { "household": { "t": "Кто живёт", "a": ["живут — 3", "рост того, кто готовит, см — 168"], "u": [], "note": "…" } }
},
"home": { "version": 2, "house": { "type": "panel", "year": "1990", "floor": 7 }, "power": { "kw": "unknown" }, "…": "…",
  "text": ["…"], "sum": { "…": "…" } }
```

- Один ответ — строка-ключ, несколько — массив ключей, `num` — число, `text` — строка. Нет ключа — нет ответа.
- `"unknown"` — «не знаю» (у `multi` — `["unknown"]`); список `группа.вопрос` продублирован в `unknown`.
- `"none"` — «нет / не нужно»; у `multi` исключает остальные ключи.
- `note` — свободная строка к группе (до 300 знаков). Скрытые условием вопросы в вывод не попадают.
- `sum` — выжимка по группам (`t` — название, `a` — «вопрос — ответ», `u` — вопросы с «не знаю», `note`). Её читает приём в движке
  (`gost-draft tools/site-brief.js`): реестр К-N строится по группам из `sum`, без разбора текста.
- `text` — та же выжимка строками для `brief.txt`.
- `tech` — тот же формат, что `life` (`version: 1`, группы `doors / devices / wiring / light / panel / low / smarthome / windecor`, `unknown`, `text`, `sum`).
- `files.now` — имена фото «как сейчас» (шаг «Дом и ремонт»), в архиве — папка `foto-seychas/`.

Поля, которые бриф дозаполняет из ответов, если клиент не написал их сам (прежние читатели брифа получают их без правок):
`answers.household / pets / wfh / storage / kitchen / sport / dislikes` (из `life`), `answers.timeline / budget` (из `home`),
`style.avoidColors` (из `life.taste.avoidColors`, словами), `budget` (класс материалов по бюджету на ремонт и площади:
до 20 тыс. ₽/м² — `econom`, до 45 тыс. — `business`, дороже — `premium`; явный выбор «Класс материалов» важнее).

## Новые ключи третьей редакции: что должен принять движок

Все ключи читаются из `brief.tech.<группа>.<ключ>`; `sum.<группа>.a` — готовые строки «вопрос — ответ» для реестра К-N, `u` — «не знаю».
Ниже — предложение, куда складывать ответы (приём пишется отдельно, по этой таблице).

| ответ | поле project.json / владелец | примечание |
|---|---|---|
| `tech.doors.kind / height / finish` | `object.brief.doors { kind[], height, finish[] }` → ведомость дверей (`architect`, `finisher`) | `hidden / pocket / slide` меняют проём и стену: К-N архитектору про короб и скрытую коробку |
| `tech.doors.hardware / threshold / acoustic` | `object.brief.doors.hardware / threshold / acoustic` | `threshold = none` — отметки пола без порогов, кроме санузла |
| `tech.doors.entrance / entranceOpt` | `object.brief.entrance { replace, options[] }` | `replace` — дверь в график до штукатурки |
| `tech.doors.closet` | `rooms[гардеробная / шкаф].doorType` | `swing` — зазор в плане, `slide` — глубина ниже |
| `tech.devices.<комната>` | `rooms[].loads[]` → `electrical-engineer`: розетки по приборам, число групп | `living / bedroom / kitchen / kids / work / bath / hall`; в санузле только розетки в допустимых зонах |
| `tech.wiring.switches` | `electrical.switches`: проходные, «выключить всё» (`allOff`), датчики движения (`motion`) | `bedPass` — проходной у кровати |
| `tech.wiring.sockets / amount / plate` | `electrical.sockets { special[], amount, plate }` | `floor / counter / low / balcony` — отдельные закладные |
| `tech.light.temp / type / dimmers / night / kitchenLight / art` | `lighting { cct, types[], dimmers[], night, kitchen[], accent }` → `colorist`, `electrical-engineer` | `temp` — 2700 / 3500–4000 / 5000 K, `mixed` — по комнатам |
| `tech.panel.always / place / surge / backup` | `electrical.panel { critical[], place, surge, backup }` | `always` → отдельные автоматы без общей группы |
| `tech.low.router / cables / wifi / tvsignal / intercom` | `lowcurrent { routerPlace, runs[], wifi, tv, intercom }` | `centre` — ниша не в металлическом щите; `cables` → трассы RJ-45 |
| `tech.smarthome.*` | `smart { level, features[], wired, scenes[], have[], platform }` | `wired = wired` — шина и подрозетники до отделки; `level = none` — остальные поля не спрашиваются |
| `tech.windecor.*` | `windows.treatment { kind[], cornice, drive }` | `cornice = hidden` — ниша в потолке; `drive = motor` — розетка в нише |
| `life.household.petNeeds` | `object.brief.pets.needs[]` | `paw` — вода и слив у входа |
| `life.sleep.bed` | `rooms[спальня].bed` | размер матраса |
| `life.future.prep` | `object.brief.reserve[]` | закладные: усиление стен, трубки |
| `home.works.bought` | `object.brief.purchased[]` | размеры и сроки поставки |
| `home.plan.crew` | `object.brief.crew` | `help` — предложить подбор бригады после оплаты |
| `life.smart.*`, `life.security.intercom` | устарели; читаются, если пришли в старом черновике | заменены `tech.smarthome.*` и `tech.low.intercom` |
