# Спецификация: рабочие чертежи электрики (ЭОМ/ЭМ) для дизайн-проекта

Собрано в сентябре 2026 по открытым источникам (Exa/Firecrawl были недоступны — только WebSearch/
WebFetch, поэтому меньше первоисточников-PDF и больше пересказов; где смог — дошёл до текста самого
пункта). Метки: **[Н]** — норма (ГОСТ/ПУЭ/СП, с номером пункта, если уверен), **[П]** — рыночная
практика студий/электриков, **[?]** — источники расходятся, не принимать как жёсткую константу.
Дополняет `docs/drawing-kb/01-gost-grafika.md` (раздел 4, графика значков) и `02-sostav-listov.md`
(разделы 6, 8, 9, 10 — общие требования к листам тёплых полов/освещения/выключателей/розеток без
привязки к конкретным пунктам ПУЭ/СП).

## 1. Состав листов раздела ЭОМ

Единого ГОСТа на «состав альбома электрики дизайн-проекта» нет (ГОСТ 21.608-2021 и 21.613-2014
регламентируют содержание документации, но не жёсткую разбивку на листы под интерьерный проект) —
разбивка на листы ниже это рыночная практика [П], сложившаяся вокруг требований 21.608/21.613.

1. **План розеток и электровыводов** — все силовые точки с назначением, привязкой и высотой;
   отдельно помечены «вывод под …» (не розетка) для мощной техники.
2. **План освещения** — светильники, группы (цветом/линией связи), тип, мощность/поток, высота
   установки не потолочных светильников [Н, ГОСТ 21.608-2021, требование к записи не потолочного
   светильника].
3. **План выключателей со связями групп** — выключатель → группа/светильники, число клавиш,
   проходные/перекрёстные узлы.
4. **План электрических тёплых полов** — контур, площадь под контуром, место терморегулятора и
   датчика, зона исключения (мебель без ножек, сантехника).
5. **Однолинейная схема щита** — вводной аппарат, счётчик, противопожарное УЗО, группы по линиям
   с аппаратами защиты [Н, по логике ГОСТ 2.702 — правила выполнения электрических схем: условность
   «одна линия = одна фаза+N+PE», сами графические знаки — по ГОСТ 2.755].
6. **Кабельный журнал / ведомость групп** — табличный лист, форма 8 по ГОСТ 21.608-2021 (или форма 7
   при трассовом методе по ГОСТ 21.613-2014) [Н, по названию форм в реестровых карточках — тело
   формы не вычитано построчно, см. `01-gost-грafika.md` п.4].
7. **Слаботочные сети** — отдельный лист (ТВ, интернет/Wi-Fi, домофон, охрана/видеонаблюдение) [Н]
   ГОСТ Р 21.618-2023 требует не смешивать слаботочку с силовой документацией.
8. **(опционально) План трасс/штроб** — часто совмещается с планом розеток и освещения: трассы
   рисуются тонкой линией поверх плана, штрихпунктир для скрытой проводки по аналогии с общим
   правилом ГОСТ 2.303-68 для невидимого контура [П, перенос общестроительной условности].

Масштаб всех листов раздела — 1:50 (крупные помещения 1:100), фрагменты/узлы щита — 1:10…1:20 —
общий масштабный ряд ГОСТ 21.501-2018 / ГОСТ 2.301-68, см. `02-sostav-листов.md`.

## 2. Условные обозначения

### 2.1. ГОСТ 21.210-2014 — «Условные графические изображения электрооборудования и проводок на
планах»
Полное официальное название подтверждено (docs.cntd.ru, vsegost.com): устанавливает изображения
электропроводок, шинопроводов, кабельных линий и электрооборудования именно **на планах** зданий —
это профильный документ для листов 1–4 раздела (розетки, освещение, выключатели, ТП). Полное тело
таблиц знаков в открытом доступе не нашлось (только карточка/область применения) — графика розеток
и выключателей ниже взята из параллельного источника (см. `01-gost-грafika.md` п.4, таблица знаков,
эталон — публикации по практике оформления, не картинка из самого ГОСТа).

### 2.2. ГОСТ 21.608-2014 / ГОСТ 21.608-2021 — рабочая документация внутреннего электроосвещения
Нормирует состав документации, а не саму графику: план, запись каждого светильника (тип, число и
мощность ламп, высота установки — кроме потолочных), группы, ведомость осветительного оборудования
(форма 4), данные щитков (форма 3), кабельный журнал (форма 8). Актуальная версия — 2021 года
(2014-я — предыдущая редакция, обе встречаются в проектах).

### 2.3. ГОСТ 2.702 — правила выполнения электрических схем
Общемашиностроительный стандарт ЕСКД: задаёт логику построения схем (в т.ч. однолинейных) —
условность изображения линии как одной черты с указанием числа проводников надписью/чёрточками,
группировку элементов по функциональному назначению, направление чтения схемы. Сама графика
аппаратов — по ГОСТ 2.755 (см. ниже), 2.702 — про правила компоновки и оформления схемы как
документа, не про рисунок конкретного автомата.

### 2.4. ГОСТ 2.755-87 — «Обозначения условные графические в электрических схемах. Устройства
коммутационные и контактные соединения»
Действующий базовый документ для символов автоматов, УЗО, контактов на однолинейной схеме щита
[Н]: коммутационные устройства рисуются в отключённом (обесточенном) начальном положении; контакт
состоит из подвижной и неподвижной контакт-детали. Точная построчная таблица знаков (автомат,
дифавтомат, УЗО) в открытых пересказах не нашлась целиком — для отрисовки в движке брать готовые
библиотечные блоки CAD/Visio с подписью «по ГОСТ 2.755», а не рисовать самодельно.

### 2.5. Практическая таблица знаков плана (расширение `01-gost-грafika.md`, статус — [П], не
буквальный ГОСТ)

| Элемент | Как подписывается на плане |
|---|---|
| Розетка обычная | значок + `h=…` при отклонении от базовой высоты проекта |
| Розетка влагозащищённая (мокрая зона) | залитый/иначе заштрихованный значок + пометка «IP44» рядом |
| Вывод кабеля (не розетка) | значок вывода/обрыва линии + текстовая подпись назначения («вывод — варочная панель») |
| Выключатель | значок + номер/буква поста, при многоклавишном — подпись «1 — свет верхний, 2 — подсветка» |
| Светильник | значок по типу (см. `01-gost-грafika.md`) + номер позиции экспликации + группа (цвет линии) |
| Группа на однолинейной схеме | номер группы, буквенно-цифровой аппарат (QF1, QF2…), назначение текстом |
| Слаботочная точка | значок + буквенная подпись назначения (ТВ, ПК/LAN, Домофон) |

## 3. Нормативные правила безопасности

### 3.1. ПУЭ 7-е издание, глава 7.1 (текст сверен по ruscable.ru/docs.cntd.ru — полный текст главы,
не пересказ)

- **п. 7.1.47** — оборудование в ванной/душевой соответствует классу защиты по зонам: зона 0 —
  IPX7, зона 1 — IPX5, зона 2 — IPX4, зона 3 — IPX1 [Н].
- **п. 7.1.48** — установка штепсельных розеток в ванных/душевых **не допускается, за исключением
  ванных комнат квартир**, где розетки допустимы **в зоне 3**, через разделительный трансформатор
  или УЗО ≤ 30 мА; любые выключатели и розетки — не ближе **0,6 м от дверного проёма душевой
  кабины** [Н].
- **п. 7.1.49** — розетки в жилых комнатах/общежитиях должны иметь защитные шторки на гнёздах
  (автоматически закрывающиеся) [Н].
- **п. 7.1.50** — минимальное расстояние от выключателей/розеток до газопроводов — **0,5 м** [Н].
- **п. 7.1.51** — выключатели рекомендуется ставить со стороны дверной ручки, на высоте **до 1 м**;
  в детских учреждениях — 1,8 м [Н, «рекомендуется», не жёсткое «обязано»].
- **п. 7.1.79** — в групповых сетях, питающих штепсельные розетки, применяется УЗО с током
  срабатывания **не более 30 мА** [Н].
- **пп. 7.1.87–7.1.88** — дополнительная система уравнивания потенциалов (ДСУП) обязательна на
  вводе здания и в ванных/душевых — к шине подключаются трубы, металлические части конструкций,
  доступные проводящие части [Н].

**[?] Расхождение по зонам 2/3.** Текст самой ПУЭ 7.1 (действует с 1999 г., правки не меняли эту
логику) использует **4-зонную схему** (0/1/2/3) старого ГОСТ Р 50571.11-96 (=IEC 60364-7-701:1984)
и прямо разрешает розетки только **в зоне 3**. Действующий сегодня отдельный стандарт зонирования —
**ГОСТ Р 50571.7.701-2013/2024** (=IEC 60364-7-701:2006/2019) — использует **3-зонную схему**
(0/1/2), без отдельной «зоны 3»: пространство за пределами зоны 2 зонами не считается вовсе. Часть
вторичных источников из-за этого путает формулировку и пишет «розетки — в зонах 2 и 3». Для проекта
LINEA — держаться буквы действующего текста ПУЭ 7.1.48 («только зона 3» = за пределами описанной в
7.1.47 зоны 2, с отступом и через УЗО 30 мА), как более консервативного и юридически актуального
требования; электрику в примечаниях сослаться на оба документа и не спорить с местным инспектором.

### 3.2. Геометрия зон (ГОСТ Р 50571.7.701, текст подтверждён двумя источниками)

- **Зона 0** — внутренний объём ванны/поддона.
- **Зона 1** — от пола до горизонтальной плоскости на высоте **2,25 м**, ограничена вертикальной
  плоскостью ванны/поддона (для душа без поддона — **0,6 м** от лейки/крана).
- **Зона 2** — следующая полоса **0,6 м** от границы зоны 1, тоже до высоты 2,25 м.
- **«Зона 3» (терминология ПУЭ 7.1, не буквальный термин актуального ГОСТ Р 50571.7.701)** — ещё
  **2,4 м** дальше от зоны 2 (значение из старого ГОСТ Р 50571.11-96, использованное в существующей
  роли `prompts/roles/electrical-engineer.md`; вторым независимым источником для точной цифры 2,4 м
  в рамках этой сессии не подтверждено — WebSearch/WebFetch не отдали текст старого ГОСТа, только
  описания зон 0–2 нового. Оставляю как унаследованное значение роли, помечаю [?] до проверки).

### 3.3. СП 256.1325800.2016 «Электроустановки жилых и общественных зданий»

- Рекомендуется разделять групповые линии: **розетки жилых комнат / освещение / розетки и
  коридорные приёмники кухни** — отдельными линиями; в обоснованных случаях допускается сократить
  до двух линий, линии могут быть смешанными или раздельными по нагрузке [Н, формулировка сверена
  по пересказу normacs.info/eng-in.ru — точный номер пункта не подтверждён, PDF отдал только
  метаданные шрифта, не текст].
- Даёт табличные значения расчётной нагрузки квартиры (пример из пересказа: квартира с усреднённой
  площадью 70 м² и электроплитой 8,5 кВт — табличная строка 7.1) и коэффициенты спроса, зависящие
  от числа розеток и конфорок плиты [Н, число подтверждено только одним пересказом — держать как
  ориентир, реальный расчёт нагрузки квартиры оставлять инженеру ЭОМ с допуском, как и оговорено в
  роли].
- Регионы имеют корректирующие коэффициенты к расчётной нагрузке по фактическому потреблению [Н,
  общее упоминание без цифр].

### 3.4. ГОСТ Р 50571.7.701 — что ещё нормирует
- В зонах 1–2 требуется присоединение ДСУП ко всем трубам, эл. приборам и открытым металлическим
  частям конструкций [Н].
- В зоне 1 — только водонагреватели с защитой не ниже IPX5 [Н].
- (см. п. 3.1 выше по поводу расхождения зон 2/3 для розеток).

## 5. Ведомость групп / таблица щита — рекомендуемая структура листа

Единой ГОСТ-формы таблицы «под интерьерный проект» не нашлось — практика собрана из нескольких
статей с примерами (u-energo.ru, 0220.ru, elec.ru) и логики ГОСТ 21.608 (форма 3 — данные щитков,
форма 8 — кабельный журнал). Рекомендуемые столбцы таблицы щита:

| № группы | Назначение / помещение | Аппарат защиты (тип, номинал) | УЗО/дифавтомат (тип, ток утечки) | Кабель (марка, сечение) | Длина, м | Точек | Расчётная мощность, кВт |
|---|---|---|---|---|---|---|---|
| Ввод | — | вводной автомат по выделенной мощности | противопожарное УЗО 100–300 мА [П] | по расчёту | — | — | — |
| 1 | Освещение, комн. 1 | C10 | — (либо общее УЗО 30 мА на группу освещения, если требуется по проекту) | ВВГнг(А)-LS 3×1,5 | — | — | — |
| 2 | Розетки, комн. 1 | C16 | УЗО/дифавтомат 30 мА | ВВГнг(А)-LS 3×2,5 | — | — | — |
| 3 | Розетки, кухня | C16 | УЗО 30 мА | 3×2,5 | — | — | — |
| 4 | Варочная панель (вывод) | C25–C32 | дифавтомат 30 мА | 3×4…3×6 (по мощности) | — | 1 | — |
| 5 | Санузел (мокрая линия) | C16 | дифавтомат 30 мА (тип A для электроники/стиральной машины) | 3×2,5 | — | — | — |
| 6 | Тёплый пол | C16–C20 | дифавтомат 30 мА | 3×2,5…3×4 | — | — | — |

Практика по типу УЗО [П]: тип **AC** — для чисто активных нагрузок (лампы накаливания, ТЭН без
электроники), тип **A** — для приборов с импульсными источниками питания (стиральная машина,
посудомойка, электроника, LED-драйверы) — расхождение источников по тому, где именно обязателен
тип A, не снято отдельным пунктом СП/ГОСТ в открытых пересказах, но как практика встречается
устойчиво в нескольких независимых материалах, поэтому фиксирую с меткой [П].

Кабельный журнал (форма 8 ГОСТ 21.608 / форма 7 ГОСТ 21.613 при трассовом методе) — отдельный
табличный лист: № линии, откуда-куда, марка и сечение кабеля, длина, способ прокладки, примечание.
Точное построчное содержание граф формы 8 в открытых пересказах не нашлось — состав таблицы выше
собран по аналогии с описанными в статьях примерами.

## 6. Обязательные примечания на листах ЭОМ

- Отметка «за 0.000 принят уровень чистого пола», привязки высот электроточек — от чистого пола, а
  не от плиты (единообразно с остальными листами альбома, см. `02-sostav-листов.md`).
- Прямая ссылка: «расчёт токов КЗ, селективности, сечений и уставок аппаратов — по проекту ЭОМ
  организации с допуском СРО»; дизайн-проект даёт состав/расположение/группы, а не инженерный
  расчёт (уже зафиксировано в роли — подтверждаю как правильную границу ответственности).
- УЗО ≤ 30 мА обязательно для всех розеточных и мокрых линий (ссылка на ПУЭ 7.1.79) — отдельной
  строкой в примечаниях к однолинейной схеме, а не только в самой таблице.
- ДСУП в санузлах — отдельное текстовое примечание со ссылкой на ПУЭ 7.1.87–88, а не только значок
  на плане (иначе монтажник может пропустить).
- Требование по кабелю: исполнение нг(А)-LS и выше для квартир (по ГОСТ 31565-2012, уже в роли).
- «Все трассы скрытой проводки — по горизонтали/вертикали от углов/проёмов/потолка с оговорёнными
  отступами; фактическую трассу зафиксировать исполнительной схемой перед закрытием отделкой» —
  страховочная формулировка, чтобы при вскрытии стены под будущий крепёж не попасть в кабель.
- Для мощной техники — явная текстовая подпись у каждого вывода («вывод — варочная панель, группа
  4», а не просто значок без подписи).

## 7. Частые ошибки проектов, ведущие к переделкам электриков

1. **Розетка вместо вывода** под варочную панель/духовку/кондиционер — при монтаже приходится
   штробить заново под нормальный вывод и менять аппарат защиты на дифавтомат нужного номинала.
2. **Общая группа для освещения и розеток** — при срабатывании защиты гаснет вообще всё в комнате;
   переделка требует новой линии от щита.
3. **Нет розетки под конкретную встраиваемую технику до заказа кухни/техники** — штробят по готовой
   отделке (частая ошибка листов 4 и 10 по `02-sostav-листов.md`, актуальна и для ЭОМ-листов).
4. **Розетка оказывается за мебелью «намертво»** — план розеток не сверен с планом расстановки
   мебели и цоколями (это же в чек-листе роли п.3 — подтверждаю важность автоматической проверки).
5. **Выключатель со стороны дверных петель** — рука утыкается в открытое полотно; ошибка привязки
   без учёта направления открывания двери с плана.
6. **Забыт проходной/перекрёстный выключатель** на длинный коридор или комнату с двумя входами —
   свет управляется только с одной точки.
7. **Мокрая линия без УЗО 30 мА** или розетка в зоне 0–2 ванной — прямое нарушение ПУЭ 7.1.48/79,
   при приёмке или проверке контролирующим органом требует переделки.
8. **Щит собран «впритык» без резерва модулей** — при любой доработке (кондиционер, второй тёплый
   пол) физически некуда ставить новый автомат, меняют щит целиком.
9. **Нет привязки высоты у части точек** («на глаз» на месте) — расхождение с мебелью/техникой,
   вскрытая после укладки плитки или установки кухни розетка не на своём месте.
10. **Слаботочка не разведена отдельно от силовой** — наводки на сигнал, путаница жил при монтаже
    (звучит и в `02-sostav-листов.md`, п.10 «частые ошибки»).
11. **Тип УЗО не соответствует нагрузке** (AC вместо A для линии со стиральной машиной/электроникой)
    — ложные срабатывания или, хуже, необнаруженные токи утечки; проверяющие организации могут
    потребовать замену.
12. **Кабель без несущей способности под фактическую расчётную мощность группы** — перегрев жилы;
    несоответствие сечения из таблицы щита реальному номиналу автомата — типичная нестыковка между
    однолинейной схемой и кабельным журналом, если их не сверяют одним и тем же инструментом.

## Что проверять автоматически в листах

Правила вида «если … то ошибка/предупреждение» — для `tools/check-sheets.js` / `tools/audit-sheets.js`
и будущего специализированного аудита ЭОМ-листов.

- Если на плане розеток есть символ **розетки** (не вывода) с координатами внутри полигона
  зоны 0/1/2 санузла → **ошибка** (нарушение ПУЭ 7.1.48).
- Если розетка/выключатель находится ближе 0,6 м (в проекции плана) от контура дверного проёма
  душевой/санузла с душем → **ошибка**.
- Если розетка/выключатель ближе 0,5 м от отмеченного на плане газопровода → **ошибка**.
- Если в помещении с типом «санузел»/«ванная» есть хотя бы одна розетка, но в таблице щита у
  соответствующей группы не указано «УЗО»/«дифавтомат» → **ошибка**.
- Если группа в таблице щита обслуживает одновременно и освещение, и розетки (по текстовому полю
  «назначение») → **предупреждение** (нарушение практики раздельных линий СП 256).
- Если у вывода мощной техники (варочная панель/духовка/кондиционер/бойлер, по ключевым словам в
  подписи) аппарат защиты — обычный автомат без пометки «дифавтомат»/«УЗО» → **предупреждение**.
- Если в рамке выключателя больше 5 постов → **ошибка** (практика серий изделий).
- Если у многоклавишного выключателя нет текстовой расшифровки, какая клавиша какую группу
  включает → **предупреждение**.
- Если координаты точки розетки/выключателя пересекаются с контуром мебели с плана расстановки
  (при наличии обоих слоёв в одном проекте) → **ошибка** («розетка за мебелью»).
- Если у точки нет атрибута высоты (`h=` / `data-h`) → **предупреждение** (кроме потолочных
  светильников — для них высота не обязательна по ГОСТ 21.608).
- Если сечение кабеля группы в кабельном журнале меньше минимально положенного для номинала
  указанного в этой же строке автомата (например, автомат ≥ 16 А при кабеле 1,5 мм² под розетки) →
  **ошибка** — сверка табличных данных однолинейной схемы и кабельного журнала на согласованность.
- Если лист «слаботочка» отсутствует, а на плане розеток встречаются символы ТВ/LAN/домофон →
  **предупреждение** (слаботочка не вынесена отдельным листом, нарушение ГОСТ Р 21.618-2023).
- Если в примечаниях листа щита нет текста про расчёт токов КЗ/селективности «по проекту ЭОМ» →
  **предупреждение** (риск, что заказчик примет дизайн-схему за инженерный проект).
- Если в помещении с электрическим тёплым полом контур пересекает контур стационарной мебели без
  ножек (по плану мебели) → **ошибка**.
