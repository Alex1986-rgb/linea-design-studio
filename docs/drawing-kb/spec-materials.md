# Профессиональная спецификация отделочных материалов и оборудования — база знаний

Собрано 21.09.26 через WebSearch/WebFetch (Exa/Firecrawl были недоступны в сессии). Числа, критичные для проекта, стоит перепроверять по актуальному ТУ/сертификату конкретной партии материала — рынок и ассортимент брендов в РФ меняются быстро.

## 0. Как оформляется спецификация (ГОСТ)

- **ГОСТ 21.110-2013** «СПДС. Спецификация оборудования, изделий и материалов» — форма 1, столбцы: позиция (поз.) → наименование и техническая характеристика → тип, марка, обозначение документа/код продукции → код продукции → завод-изготовитель → единица измерения → количество → масса ед., кг → примечание. Спецификацию делают к каждому основному комплекту рабочих чертежей (кроме ЖБК/КМ/КД), титульный лист — по форме 15 ГОСТ 21.101, обозначение = шифр комплекта + «.СО». *(источник — cntd.ru, garant.ru, единственный источник по деталям формы, но норма общеизвестная и не спорная)*
- **Ведомость отделки помещений** — сейчас регламентируется **ГОСТ 21.501-2018** (старый 21.501-93/2011 отменены), приложение А. Число граф не фиксировано жёстко — определяется составом элементов отделки (пол/плинтус/стены/перегородки/потолок/проёмы), размеры граф задаёт сам разработчик. Обязательно: помещение (номер по экспликации), вид отделки по каждому элементу, площадь, примечание.
- Для дизайн-проекта интерьера (не только рабочей документации по СПДС) на практике добавляют отдельно:
  - **спецификацию материалов** (краски, обои, плитка, покрытия пола — с точным названием бренда/коллекции/артикула/цвета, расходом и количеством упаковок);
  - **спецификацию сантехники, электрики и света** (модель, IP, мощность, цветовая температура);
  - **ведомость дверей и проёмов** (тип, размер, направление открывания, фурнитура).

## 1. Краски и шпаклёвки

**Что указывает проектировщик:**
- тип связующего (акриловая/латексная/силикатная/силиконовая), степень блеска (глубокоматовая / матовая / шёлковая / полуглянец);
- класс истираемости покрытия (класс 1 по EN 13300 — самый стойкий, для влажной уборки/кухонь);
- паропроницаемость — критично для «дышащих» стен и минеральных штукатурок;
- расход л/м² на слой и число слоёв — берётся из ТУ конкретного продукта, типовая вилка для интерьерной водно-дисперсионной краски **0,10–0,15 л/м² на слой** (2 слоя = 0,20–0,30 л/м²), справочно встречается запись «100–150 г/м² на слой» (для красок плотностью ~1 кг/л это то же самое); для известковых красок первый слой ощутимо прожорливее второго (пример из источников: 550 г/м² первый слой / 350 г/м² второй — **справочная цифра одного источника, не universal**);
- класс пожарной опасности (для путей эвакуации — не ниже КМ1/показатели Г1,В1,Д2,Т2,РП1, см. раздел 5);
- для помещений с влагой — маркировка «влагостойкая», класс мокрого истирания.

## 3. Плитка и керамогранит

**Обязательные технические характеристики:**
- **Водопоглощение** по ГОСТ 13996-2019 — керамогранит определён как плитка с водопоглощением ≤ 0,5%. Классы по водопоглощению (аналог EN 14411): группа BIa (≤0,5%, керамогранит) / BIb (0,5–3%) / BIIa (3–6%) / BIIb (6–10%) / BIII (>10%) — деление на группы стандартное для линейки EN, в русскоязычных источниках чаще фигурирует упрощённо как «водопоглощение до 0,5%» без явной таблицы групп (единственный источник по цифре 0,5%, но это общепринятый факт отрасли).
- **PEI (класс износостойкости поверхности)** — I (без хождения) … V (интенсивный поток, общественные пространства); для пола в квартире обычно достаточно PEI III–IV, для входных групп/коммерции — PEI IV–V.
- **Калибр** — рабочий (номинальный) размер, к которому должен соответствовать фактический размер плитки в пределах допуска; указывается на упаковке отдельным числом на партию.
- **Ректификат** — плитка с механически обработанной кромкой, все плитки партии приведены к одному калибру — даёт минимальный шов (1,5–2 мм).
- **Класс противоскольжения** (DIN 51130, метод наклонной платформы «в обуви + масло»):
  | Класс | Угол наклона | Применение |
  |---|---|---|
  | R9 | до 10° | сухие жилые помещения (спальня, гостиная, коридор) |
  | R10 | 10–19° | кухни, санузлы, гаражи |
  | R11 | 19–27° | прачечные, бани/сауны общего пользования |
  | R12 | 27–35° | промышленные кухни, цеха, спецпомещения |
  | R13 | >35° | только спецзоны промышленных объектов |
  Для жилого интерьера — санузлы и кухни минимум R10, для террас/бассейна на улице — R11+.
- Толщина/формат: указывать номинальный размер и фактический (мм), калибр партии.

## 4. Ламинат, инженерная доска, паркет, кварцвинил (SPC/ПВХ)

**Ламинат:**
- Класс износостойкости **AC1–AC5** по EN 13329 / российский аналог **ГОСТ 32304-2013** (де-факто соответствует EN). Двузначная маркировка 21–34: первая цифра — тип помещения (2 — бытовое, 3 — коммерческое), вторая — интенсивность нагрузки (1 лёгкая…4 очень высокая). Для квартиры — 32–33 класс (AC4), для повышенной проходимости и коммерции — 33–34 (AC5).
- **Эмиссия формальдегида**: базовые ГОСТ — 10632-2014 (ДСП) и 32274-2021 (МДФ), классы **E0,5 / E1 / E2** с предельными значениями (справочно) 4 / 8 / 20 мг/100 г сухого материала соответственно. Официального класса «E0» в стандартах нет — часто маркетинговое обозначение, для жилых помещений спецификатор указывает конкретный протокол испытаний, не полагаясь на надпись «E0» на упаковке.
- Для комбинации с тёплым полом суммарное термическое сопротивление ламината + подложки не должно превышать **0,15 м²·К/Вт**; подложка под тёплый пол — специальная тонкая (до 2–3 мм), с маркировкой производителя «для тёплых полов».

**Инженерная доска/паркет:** указывать породу, толщину рабочего слоя шпона, тип покрытия (масло/лак), способ укладки (пряморядная/ёлка/шашка) — от этого напрямую зависит запас на подрезку.

**Кварцвинил (SPC):** толщина защитного слоя (0,3–0,7 мм для жилых помещений), общая толщина плитки, класс использования (аналог 32/33/34 или коммерческий 42/43).

## 7. ГКЛ и профили

- **ГКЛ** — обычный (ГСП-Н), **ГКЛВ** (влагостойкий, ГСП-Н2 — для санузлов, кухонь, техпомещений), **ГКЛО** (огнестойкий — для облицовки печей/каминов, путей эвакуации), **ГКЛВО** (совмещённый).
- Стандартный формат листа: 2500×1200×12,5 мм (варианты длины 2000–4000 мм, толщина 6,5/8/9,5/12,5/14/16 мм).
- Разница по весу заметная у разных заводов: у Волма ГКЛВ 2,5×1,2×12,5 мм ≈ 37,5 кг/лист, у Кнауф аналог ≈ 25 кг — при подборе учитывать нагрузку на каркас и логистику.
- Бренды: **Кнауф** и **Волма** — два основных игрока рынка РФ; профили — Кнауф (только толщина 0,6 мм, точная геометрия, дороже) vs прочие производители (0,35–0,6 мм).

## 8. Двери и плинтусы скрытого монтажа

- Скрытые двери (invisible/hidden doors): полотно заподлицо со стеной, короб под оклейку тем же материалом, что и стена (обои/покраска), либо готовая эмаль в цвет; фурнитура — скрытые петли, магнитный доводчик/замок.
- Скрытый (теневой) плинтус — алюминиевый профиль, монтируется в подготовленную нишу до финишной отделки стен, зазор маскирует деформационный шов, может включать канал для проводов/светодиодной ленты.

По прямому веб-поиску 2025–2026 подтверждена активность на рынке у **Profilpas** (алюминиевые плинтусные профили, включая скрытые) и нишевых производителей скрытых дверей (например, Shadow Doors, Pro Design — производители теневого плинтуса) — конкретные позиции по Sofia/Sarto/Prostor поиском не подтверждены, оставляю как есть из presets.js без дополнительного подтверждения (`—`).

## 11. Светильники

- **IP-зонирование ванной по ПУЭ**: зона 0 (внутри ванны/поддона) — только СНН до 12В, IP67; зона 1 (над ванной/душем до 2,25 м) — минимум IP45; зона 2 — не ниже IPX4. Для кухонь/техпомещений над мойкой — не ниже IP44.
- **CRI (Ra)** — индекс цветопередачи от 0 до 100 (100 = эталон дневного света). Для жилых интерьеров рекомендуется **Ra ≥ 80–90**, для зон с макияжем/готовкой/гардеробных — стремиться к Ra ≥ 90–95.
- **Цветовая температура**: 2700 К — тёплый уютный свет для жилых зон (спальня, гостиная), 3000–4000 К — рабочие/кухонные зоны, нейтральный. CRI и цветовая температура — независимые параметры, указывать оба.
- Бренды: **Maytoni, Arlight, Elektrostandard** — российские бренды массового и среднего сегмента (в т.ч. используются в presets.js студии: Arlight — лента/профиль, Maytoni — трек-система); премиум — **Artemide, Flos** (упомянуты как элитный сегмент, доступность в РФ 2025–2026 требует проверки у конкретного дистрибьютора на момент закупки).

## 12. Стеклянные перегородки

- Материал — закалённое стекло или триплекс (многослойное, минимум 2 закалённых слоя со плёнкой/смолой между ними — при разрушении не рассыпается, остаётся целостным).
- Толщина для квартирных нестационарных/лёгких перегородок — 5–8 мм; для перегородок на точечных креплениях без рамы — 8–12 мм (даёт запас прочности, шумоизоляцию, безопасность).
- Закалённое стекло прочнее обычного в 5–8 раз, но твёрже в обработке (вырезы/отверстия делаются только до закалки).
- К спецификации: тип стекла, толщина, способ крепления (точечное/шинное/каркасное), тип фурнитуры (для раздвижных систем — производитель направляющих), наличие плёнки безопасности/матирования.

## 13. Класс пожарной опасности отделки — важное уточнение

С **июля 2022 года классы КМ0–КМ5 официально исключены из нормативной базы** 123-ФЗ (в редакции ФЗ-imperative обновлений техрегламента). Требования теперь задаются напрямую показателями пожарной опасности: **Г (горючесть), В (воспламеняемость), Д (дымообразующая способность), Т (токсичность продуктов горения), РП (распространение пламени по поверхности)** — например «Г1, В1, Д2, Т2, РП1». На путях эвакуации, в детских, медицинских, социальных учреждениях материалы ниже прежнего КМ1 (сейчас — конкретный набор показателей) запрещены; в местах массового пребывания людей и на путях эвакуации запрещены материалы прежнего уровня КМ5.

**Для практики LINEA**: в жилых квартирах номенклатура КМ формально не обязательна (это не общественное здание с нормируемыми путями эвакуации), но если студия делает проекты для апартаментов в МКД с общими коридорами/лестничными клетками, или коммерческие интерьеры (шоурум, офис, ресепшн бизнес-центра) — в спецификацию отделки этих зон нужно вносить показатели Г/В/Д/Т/РП по сертификату, а не устаревшую букву «КМ», которую иногда ещё используют производители в рекламных материалах по инерции.

## 15. Совместимость материалов

- **Плиточный клей C1/C2 (EN 12004)**: C1 — базовый (адгезия от 0,5 МПа, для впитывающих оснований, сухих помещений); C2 — улучшенный (адгезия от 1,0 МПа, для керамогранита, крупного формата, сложных оснований). Индексы S1/S2 — повышенная эластичность, обязательны при укладке на тёплый пол, гипсокартон, деревянное основание, подвижные/деформирующиеся конструкции.
- **Тёплый пол + напольное покрытие**: суммарное термическое сопротивление покрытия и подложки **не более 0,15 м²·К/Вт** — иначе теплоотдача падает, а перегрев нижних слоёв ламината/паркета вызывает деформацию. Для тёплого пола — только тонкие спецподложки (2–3 мм) с маркировкой производителя «для тёплых полов», замковая система Click предпочтительна для ламината. Керамика/керамогранит — исторически «безупречное» сочетание с тёплым полом (низкое термосопротивление, высокая теплопроводность).
- **Краска по влажным помещениям**: для санузлов и кухонь — маркировка «влагостойкая»/«моющаяся» с классом мокрого истирания (класс 1 по EN 13300 — выдерживает интенсивную влажную уборку); для минеральных декоративных штукатурок — паропроницаемость важна при утеплённых/«дышащих» стенах, чтобы не создавать конденсат под плёнкообразующим покрытием.

## Что улучшить в presets.js и спецификации движка

1. **В `STYLES[key].skus` нет технических характеристик — только бренд/артикул.** Для реальной рабочей спецификации (не только концепт-борда) нужно на каждый SKU дописывать структурой: класс износостойкости/PEI, водопоглощение, R-класс, IP, CRI/Кельвины, класс пожарной опасности (Г/В/Д/Т/РП, не устаревшее «КМ»). Сейчас в движке это придётся добавлять вручную в каждый бриф/отчёт — стоит завести отдельный объект `SPEC` рядом со `skus` в `presets.js`, например:
   ```js
   spec: {
     floor: { class: 'AC5/33', emission: 'E1', warmFloorReady: false },
     tile:  { pei: 'IV', waterAbs: '≤0.5%', slip: 'R10', rectified: true },
     led:   { ip: 'IP20', cri: 90, cct: '3000K' }
   }
   ```
2. **Нет полей для санузлов/кухонь** (IP, R-класс, C1/C2 клей) — пресеты сейчас описывают только гостиную/спальню-ориентированный набор (пол/потолок/двери/плинтус/led), а инсталляции/смесители/трапы/электрика вообще не входят в `STYLES`, хотя есть в `FURN_PRICES` (bath, wc, sink) без техпараметров.
3. **`WORK_RATES.tile`** объединяет «стены/пол» одной строкой — в реальной ведомости работ раскладка клея/расход отдельно по полу (C2, крупный формат) и стенам (C1, лёгкая плитка) — стоит разделить расценку или хотя бы добавить примечание про класс клея.
4. **Нет учёта запаса на подрезку и упаковку** при расчёте `FURN_PRICES`/`floor.priceM2` — расчёт сметы явно берёт «голую» площадь без +5…15% на подрезку/бой и без округления в кратные упаковке количества (мешки клея, коробки плитки/ламината). Это может занижать итоговую смету клиенту.
5. **Класс пожарной опасности** нигде не упоминается в движке — если студия когда-нибудь возьмёт коммерческий объект (шоурум, офис, апартаменты с местами общего пользования), в презентации/спецификации понадобится отдельное поле, которого сейчас в `presets.js` структурно нет.
6. **Разночтения по IP/CRI у LED**: в `skus.led` указана только модель ленты/профиля («Warm3000», «Day4000»), но не IP и не CRI — для влажных зон (санузел, кухонная подсветка) это критично и сейчас никак не зашито в пресет.

## Автопроверки

Что можно добавить в `engine/validate.js` или отдельный линтер спецификации без большого рефакторинга:

1. **Проверка наличия IP-класса у LED/светильников в мокрых зонах** — если помещение брифа помечено как санузел/кухня (по `room.type` или названию), а в `skus.led`/спецификации нет явного IP ≥ IP44 — предупреждение.
2. **Проверка совместимости «тёплый пол + покрытие»** — если в брифе включён тёплый пол (`object.heating` или аналог) и выбран стиль с деревянным полом (инженерная доска/паркет/массив без явной пометки «подходит для тёплого пола») — предупреждение, что термосопротивление нужно подтверждать по ТУ.
3. **Проверка запаса материала при генерации сметы** — коэффициент запаса (5–15% в зависимости от способа укладки, задаваемого в брифе) применять к `floor.priceM2 × area` и к расчёту клея/подложки, а не считать по «голой» площади.
4. **Линт на устаревшую маркировку «КМ»** — если в текстах пресетов/презентации где-либо появится ссылка на «класс КМ1» и т.п. без указания конкретных показателей Г/В/Д/Т/РП — предупреждение, что с июля 2022 это не действующая формулировка 123-ФЗ.
5. **Проверка полноты SKU** — простой скрипт, сверяющий, что у каждого `STYLES[key].skus.*` заполнено поле бренда (не `—`) и (после внедрения пункта 1 из раздела выше) поле `spec` — не даёт пресету «расползтись» при добавлении новых стилей.
