# 11. Графика рабочих чертежей: как оформляют листы практикующие бюро

Источник: разбор 89 чертежей квартир, домов и ремонтов из открытой выдачи Яндекс.Картинок
(21.09.2026). На листах встречаются бюро REMPLANNER, WOWROOM, KOMFORTNO74, DYNAMIC DESIGN, ЕвроДом,
ISB Design. Здесь только выводы, сами картинки не публикуются.

## 1. Типы листов

| Лист | Что на нём обязательно |
|---|---|
| Обмерный план | высота потолка (Н пот.), привязки проёмов, стояки, радиаторы, толщины стен |
| Демонтаж | демонтируемое красным контуром или штриховкой, остальное серым |
| Монтаж перегородок | цвет или штриховка по типу (ГКЛ, ГКЛ со звукоизоляцией, пеноблок) + легенда |
| Расстановка мебели | мебель с габаритами, привязки к стенам, спецификация с номерами позиций |
| Отделка стен | цветные линии по внутреннему периметру, легенда материалов |
| Полы | штриховка по типу покрытия, легенда, пороги и стыки, направление укладки |
| Потолки | отметки уровней, контуры перепадов, материалы |
| Освещение и выключатели | символы красным, линии групп от выключателя к светильникам |
| Розетки | высоты выносками (Н=300 / 900 / 1100), назначение |
| Сантехника / водопровод | трубы цветом: В1 (ХВС), Т3 (ГВС), Т4 (циркуляция), К1 (канализация) |
| Развёртки санузла | раскладка плитки, выводы, стрелка начала раскладки |
| Развёртки комнат | виды стен A–D, привязки электрики, высоты |

## 2. Общая графика листа

- Стены — тёмная заливка или штриховка по материалу; мебель и сантехника — тонкие линии.
  Контраст «толстые стены / тонкая мебель» делает план читаемым.
- Размеры снаружи в 2–3 цепочки: проёмы и простенки → помещения → габарит. Внутри — только привязки.
- Помещение: номер в кружке, площадь подчёркнута (14,32 м²).
- Экспликация — таблица справа: №, наименование, площадь, итог.
- Блок условных обозначений на каждом листе, где есть цвет или символы.
- Примечания — нумерованный список над штампом.
- Штамп по ГОСТ в правом нижнем углу: стадия РП, лист, листов, масштаб, название.
- Масштабы: 1:50 основной, также 1:40, 1:75, 1:100. Встречающийся 1:70 — нарушение ГОСТ 2.302.
- Координационные оси (буквы/цифры в кружках) — на части листов.
- Цвет несёт смысл (тип перегородки, материал, трубопровод) и всегда дублируется легендой.

## 3. Что забрать в движок LINEA

1. Цвет без легенды на листе — ошибка аудита.
2. Номер помещения в кружке и подчёркнутая площадь — на всех планах.
3. Высота электроточки выноской «Н=…» у символа.
4. Стрелка начала раскладки плитки на развёртке санузла.
5. Маркировка трубопроводов В1/Т3/Т4/К1 на плане сантехники.
6. Масштаб только из ряда ГОСТ 2.302: 1:70 и 1:30 запрещать.
