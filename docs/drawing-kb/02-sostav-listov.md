# Состав листов рабочей документации дизайн-проекта — практика РФ

Свод по открытым источникам (студии, школы дизайна, форумы dwg.ru, блоги). Единого ГОСТа на
«дизайн-проект интерьера» нет — де-факто стандарт задаёт рынок (студии, школы). Там, где есть
привязка к нормативке (ГОСТ 21.501, ГОСТ 2.306-68, СП 31-110), это указано отдельно. Цифры
(высоты, зазоры, люксы) — из нескольких независимых источников, где они совпали; расхождения
помечены явно.

Общие вещи, верные почти для всех листов:
- Синий цвет — обычные размерные линии; красный — привязки розеток/выключателей/критичные размеры,
  которые нельзя перепутать на площадке.
- Единая легенда условных обозначений — одинаковая на всех листах альбома, не перерисовывается заново.
- Штамп/рамка листа: название чертежа, масштаб, дата, номер листа/из скольких, объект, ГИП/автор.
- Примечание «за отметку 0.000 принят уровень чистого пола» и «все размеры проверить на объекте
  до начала работ / до заказа материалов» — стандартная страховочная формулировка почти на каждом листе.
- Масштабный ряд по ГОСТ 21.501-2018: планы/развёртки — 1:50 (для больших помещений 1:100),
  узлы и фрагменты — 1:10…1:20, самые мелкие детали — 1:1…1:5. Узел выносится в масштаб по степени
  проработки, а не подгоняется под лист.

## 1. Обмерный план

**Обязательные элементы**
- Фактические (не проектные) размеры: длины стен, толщины стен/перегородок, высота потолков по факту.
- Все проёмы (окна, двери) с шириной и привязкой, подоконники.
- Ниши, выступы, короба, колонны, эркеры, скошенные стены — со своими размерами.
- Инженерные выводы «как есть»: стояки, вентканалы, существующая электрика/сантехника (где видно).
- Обозначение сторон света, наименования и площади помещений.

**Размерные цепочки / привязки**
- Цепочка размеров по периметру каждой стены + диагонали помещений (проверка прямоугольности).
- Толщина стен указывается отдельным размером в разрыве стены, а не «на глаз».

**Условные обозначения / легенда** — общие ГОСТ-обозначения стен, проёмов, сантех. приборов «как есть».

**Типовые примечания** — «размеры сняты на месте, отметка 0.000 = существующий пол», ссылка на
дату обмера (планировка могла измениться).

**Частые ошибки, ведущие к переделкам**
- Обмер без диагоналей — «прямоугольная» комната на бумаге на деле оказывается трапецией.
- Использование плана БТИ вместо реального обмера (расхождения после чистовой отделки).
- Не зафиксирована фактическая высота потолка по углам (перепад).

**Масштаб**: 1:50 (мелкие помещения — 1:25/1:20 для читаемости).

Источники: cian.ru, vc.ru/dizain-interior, mostpr.ru, geometrium-school.ru.

## 2. План демонтажа

**Обязательные элементы**
- Название листа, масштаб, штамп, дата.
- 1–2 общих 3D-вида для наглядности (по рынку — частая практика, не norma).
- Помечены демонтируемые элементы: перегородки (кроме несущих — отдельно и явно «не трогать»),
  дверные блоки и проёмы, подоконники/окна под замену, радиаторы, старые покрытия пола/стен/потолка,
  сантехприборы под снос.
- Спецификация помещений (что убрано, что остаётся).
- 3D-узлы сложных мест демонтажа (частичный снос стены, штраба) с размерами и высотами.

**Размерные цепочки / привязки**
- Размеры демонтируемых проёмов/участков стен — критичные размеры красным.
- Высота частично демонтируемой перегородки указывается отдельно.

**Условные обозначения**
- ГОСТ 2.306-68: штриховка сносимых конструкций (обычно перекрёстная/косая штриховка,
  штриховые линии по контуру «под снос»); несущие стены — заливка/иная штриховка, «демонтаж запрещён».

**Типовые примечания**
- «За условную отметку 0.000 принята отметка существующего пола».
- Прямой запрет: «Демонтаж несущих стен и плит перекрытия не производится / согласовывается отдельно».
- Требование проверить размеры на месте перед демонтажными работами.

**Частые ошибки**
- Не выделена явно несущая стена — рабочие сносят капитальную конструкцию.
- Нет указания, что делать со стояками/шахтами при демонтаже коробов вокруг них.
- Забыли указать демонтаж подоконных блоков/откосов при замене окон.

**Масштаб**: 1:50.

Источники: gavrilova-bim-design.ru/plan_demontazha, docs.cntd.ru (ГОСТ 21.501-2018),
spds.ru (ГОСТ 2.306-68).

## 3. План монтажа (возводимых перегородок)

**Обязательные элементы**
- Легенда материалов перегородок (ГКЛ на металлокаркасе, газобетон, пеноблок, стекло и т.д.)
  с указанием толщины и типа шумоизоляции.
- Высота перегородки до потолка (не всегда до плиты — бывает подвесной потолок).
- Армирование/усиление проёмов под двери и тяжёлые конструкции (например, под скрытые петли).
- Ведомость дверных блоков: тип (входная/раздвижная/межкомнатная/проём без двери),
  сторона открывания, размер проёма, материал полотна.
- Сечения вертикальных шахт/коробов под коммуникации.

**Размерные цепочки / привязки**
- Привязка новых перегородок от капитальных стен или координационных осей (не «от соседней перегородки»,
  чтобы ошибка не накапливалась).
- Привязка дверных проёмов от угла/оси, а не только от края перегородки.
- Толщина перегородки — отдельным размером.

**Условные обозначения** — новые конструкции заливкой/штриховкой, отличной от плана демонтажа
и от существующих стен; направление открывания дверей — дуга со стрелкой.

**Типовые примечания**
- Требование по звукоизоляции межквартирных/санузловых перегородок.
- «Важные примечания, специфичные для проекта — выделять красным/рамкой» — общая практика студий.

**Частые ошибки**
- Привязка «по цепочке» от предыдущей перегородки — суммарная ошибка на весь коридор.
- Не указана высота перегородки при опущенном коробе/потолке — рабочие доводят до плиты.
- Забыли усиление стены под навесную сантехнику/тяжёлую мебель.

**Масштаб**: 1:50.

Источники: topdom.ru/gallery/projects/1/3.htm, vipdesire.ru, decorator-studio.ru.

## 4. План расстановки мебели и оборудования

**Обязательные элементы**
- Габаритные контуры всей мебели и техники в масштабе, включая открывание дверей/ящиков
  (дуги открывания шкафов, холодильника, духовки).
- Проходы между мебелью с указанием минимальной ширины.
- Привязка мебели к стенам/окнам/дверным проёмам.
- Разметка функциональных зон.

**Размерные цепочки / привязки**
- Привязка мебели от ближайшей капитальной стены/угла — не от других предметов мебели.
- Ширина проходов — отдельная размерная цепочка.
- Для встроенной мебели (кухня, шкафы) — привязка от коммуникаций (розетка/вывод воды под мебель).

**Условные обозначения** — единый набор пиктограмм мебели/техники по каталогу студии, легенда на листе.

**Типовые примечания** — «схема мебели не является технической документацией для производства» —
частая оговорка (детальные размеры мебели даются отдельным чертежом/спецификацией).

**Частые ошибки**
- Не учтён радиус открывания дверец шкафа/холодильника — упирается в стену или другую мебель.
- Не сверено с планом розеток/тёплого пола — розетка оказывается за шкафом «намертво».
- Мебель «впритык» без вентиляционных зазоров у встраиваемой техники.

**Масштаб**: 1:50.

Источники: remplanner.ru, flatica.ru, design-class.com.ua, geometrium-school.ru.

## 5. План полов / раскладка напольных покрытий

**Обязательные элементы**
- Тип покрытия по каждому помещению/зоне с цветовой заливкой по материалам.
- Площадь покрытия по зонам (для закупки).
- Линии переходов между материалами, места и тип порогов.
- Направление укладки (важно для планок/паркета/ламината) и рисунок раскладки (палуба, ёлка, шахматка).
- Обозначение зон с тёплым полом (перекрёстная ссылка на отдельный лист теплого пола).
- Гидро-/шумоизоляция по помещениям, разница уровней стяжки между зонами (например, санузел ниже).

**Размерные цепочки / привязки**
- Привязка точки старта раскладки (обычно от входной двери, окна или самой длинной стены).
- Размеры порогов/примыканий отдельными выносками.

**Условные обозначения** — штриховка/заливка по типу покрытия + стрелка направления укладки.

**Типовые примечания** — направление «по свету» или «по ходу движения»; какой стороной парта
класть у входа.

**Частые ошибки**
- Не указано направление укладки — доска легла поперёк света, все стыки видны.
- Не согласован уровень стяжки на стыке разнотолщинных покрытий (плитка/паркет) — порог получается
  кривым по факту.
- Забыт порог в дверном проёме между разнородными покрытиями.

**Масштаб**: 1:50.

Источники: my-dom.design/plan-napolnyh-pokrytij, m.zems.pro/plan-polov, topdom.ru,
evroplast-rt.ru, meister24.ru.

## 6. План тёплых полов

**Обязательные элементы**
- Тип системы (водяной/электрический кабельный/маты) отдельно по зонам.
- Контур укладки: шаг, направление, места подключения/разветвления.
- Расположение коллектора, термостатов, датчиков температуры.
- Зона, где тёплый пол НЕ укладывается (под стационарной мебелью без ножек, под ванной/душевым поддоном).

**Размерные цепочки / привязки**
- Отступ контура от стен — не менее 10 см (по нескольким источникам).
- Зазор контура от мебели без ножек (шкафы, кухонные тумбы) — 15–30 см, синхронизировано с планом
  расстановки мебели.
- Длина контуров примерно равная — для равномерного прогрева (проектный принцип, не размерная цепочка
  на чертеже, но проверяемое требование).

**Условные обозначения** — линия контура с шагом укладки, значок коллектора/термостата/датчика.

**Типовые примечания** — «сверить с планом мебели перед укладкой», указание мощности/сопротивления
контура (для электрического).

**Частые ошибки**
- Контур уложен под шкафом без ножек — перегрев и порча покрытия/мебели.
- Не согласовано с планом мебели/розеток — теплый пол пробит крепежом плинтуса или ножки мебели.
- Разная длина контуров в одной зоне — неравномерный прогрев.

**Масштаб**: 1:50.

Источники: teploluxe.by, topdom.ru/gallery/projects/1/7.htm, akvilonpro.ua.

## 7. План потолков

**Обязательные элементы**
- Материал и конструкция потолка по зонам (натяжной, ГКЛ одно-/двухуровневый, окрашенный) — цветовой код.
- Отметки уровней и величина перепадов (высота от чистового пола до каждого уровня потолка).
- Ниши для штор (карнизные) — сечение и размеры.
- Короба (для вентиляции/кондиционирования, для скрытой подсветки) — контур и высота.
- Места под потолочные карнизы, розетки/молдинги (декор), закладные под тяжёлые светильники.
- Люки ревизии.

**Размерные цепочки / привязки**
- Отметки уровней от отметки 0.000 (чистый пол) или от плиты перекрытия — обязательно указать,
  от чего считается.
- Ширина/глубина ниш и коробов — отдельные размеры на плане + вынос в узел.

**Условные обозначения** — штриховка/заливка по типу материала, отметка уровня (±0.000 стиль),
линия перепада (уступа).

**Типовые примечания** — материал каркаса, тип ГКЛ (влагостойкий в санузле/кухне), необходимость
закладных под люстру/точечные светильники большого веса.

**Частые ошибки**
- Не указана высота короба под вентиляцию — конфликт со шкафом или дверным проёмом.
- Перепад уровня не согласован с высотой шкафа-купе (потолок «режет» верх шкафа).
- Забыт люк ревизии над сантехническими стояками/коллектором.

**Масштаб**: 1:50 (сложные многоуровневые потолки — фрагменты 1:20).

Источники: topdom.ru/gallery/projects/1/8.htm, my-dom.design/plan-potolkov, m.zems.pro/plan-potolkov,
render.ru (памятка для визуализаторов).

## 8. План освещения

**Обязательные элементы**
- План потолка (и, при необходимости, стен/пола) со всеми светильниками.
- Цветовая кодировка типов света: общий, рабочий, акцентный, ночной, декоративный (5 слоёв).
- Экспликация светильников с параметрами (тип, мощность, световой поток, цветовая температура, IP).
- Таблица сценариев освещения (если есть управление сценами).
- Разрезы/узлы сложных мест (ниша с подсветкой, скрытый карниз).
- Привязка каждого светильника размерами от стен/осей.

**Размерные цепочки / привязки (ориентиры из нескольких источников)**
- Подвес над обеденным столом — 65–75 см от столешницы до низа плафона.
- Настенные бра/светильники — с отступом 40–60 см от фасада шкафа при потолке 2,7–3,0 м.
- Контурная подсветка ниши для штор — отступ 5–10 см от края.
- Освещённость по зонам (лк, ориентировочно): прихожая 100–150, гостиная 150–200, кухня 300–500,
  санузел 200–300.
- Цветовая температура: 2700–3000K — зоны отдыха, 3000–3500K — кухня, 4000K — рабочие/офисные зоны.
- CRI ≥ 90 для жилых помещений.

**Условные обозначения** — отдельные значки для точечных, подвесных, встроенных светильников,
трек-систем, лент; цвет/штриховка по группе/сценарию.

**Типовые примечания** — тип диммирования/управления (DALI, диммер, умный дом), IP-класс во влажных
зонах.

**Частые ошибки**
- Единственный центральный светильник — тени по периметру, нет слоёв света.
- Расстановка «по сетке» без учёта мебели — споты бьют в дверцы шкафов, блики на экранах ТВ.
- Разная температура света в едином открытом пространстве — визуально режет зону на части.
- Лента без профиля/рассеивателя — видны отдельные диоды, пыль скапливается в канале.
- Нет диммирования — свет не масштабируется под сценарий (день/вечер/кино).

**Масштаб**: 1:50 (иногда 1:100 для общего обзора + фрагменты 1:20).

Источники: kubstudioschool.ru (недоступен напрямую, данные через смежные источники),
blog.isakovadesign.ru, ledrus.org, vipdesire.ru, decorator-studio.ru.

## 9. План выключателей и схема включения

**Обязательные элементы**
- Расположение каждого выключателя/поста управления с указанием количества клавиш.
- Явная привязка «выключатель → какая группа/какие светильники» (стрелки-выноски или единая
  цветовая маркировка групп на плане освещения и плане выключателей).
- Проходные и перекрёстные выключатели там, где вход/выход из помещения в двух точках (коридор,
  спальня с двумя входами, лестница).
- Схема принципиального подключения (L — фаза, N — ноль, PE — заземление) для электрика,
  отдельно от плана привязок для монтажника-отделочника.

**Размерные цепочки / привязки**
- Высота установки выключателя от чистого пола: 90–100 см — устойчивый ориентир по нескольким
  источникам (встречается также вариант «на уровне дверной ручки», это соответствует тому же
  диапазону).
- Привязка от дверного проёма/угла (с какой стороны от дверного полотна, на каком расстоянии,
  чтобы не перекрывалась открытой дверью).

**Условные обозначения** — количество клавиш (пиктограмма 1/2/3-клавишного выключателя),
проходной выключатель — отдельный значок, цвет линии/выноски = группа освещения.

**Типовые примечания** — какая клавиша какую группу включает (текстовая расшифровка рядом
с каждым многоклавишным постом), тип выключателя (проходной/перекрёстный/диммер/сенсорный).

**Частые ошибки**
- Выключатель со стороны петель двери — рука утыкается в открытую дверь.
- Не указано, какая клавиша что включает — на объекте путают группы, потом заказчик недоволен.
- Забыт проходной выключатель на длинный коридор/лестницу — свет выключают только с одной стороны.

**Масштаб**: 1:50.

Источники: my-dom.design/plan-vykljuchatelej, vashelektrik24.ru (пример PDF-листа),
220blog.ru, elec.ru.

## 10. План розеток и электровыводов

**Обязательные элементы**
- Все силовые розетки и выделенные электровыводы (под встраиваемую технику, кондиционер, тёплый пол,
  бойлер) с указанием назначения текстом.
- Слаботочные точки отдельно: ТВ/интернет/Wi-Fi точка доступа, охранная/видеонаблюдение, домофон.
- Группировка по автоматам/УЗО там, где это существенно для монтажника (мокрые зоны — отдельная группа
  с УЗО).

**Размерные цепочки / привязки — высоты по назначению (ориентиры, встречались расхождения в источниках)**
- Общие «евростандарт»-розетки: часто указывают базовую высоту около 30 см от пола (встречается и
  диапазон, привязанный к конкретной мебели — приоритет у эргономики над «стандартом»).
- Кухня, розетки на фартуке для мелкой техники: 105–115 см от пола (10–20 см над столешницей).
- Кухня, розетки под встраиваемую крупную технику (холодильник, посудомойка, стиральная, духовка):
  10–30 см от пола, для духового шкафа/варочной панели отдельно встречается 18–20 см.
- Розетка под вытяжку/подсветку: 215–240 см от пола.
- Розетка под варочную поверхность/плиту (не встраиваемую): 60–70 см от пола (по отдельным
  источникам) — сверять с моделью техники, единого числа по рынку нет.
- ТВ-розетка: привязывается индивидуально под конкретный телевизор/крепление (единого норматива
  в источниках не нашлось — считать проектной величиной, не «стандартом»).

**Условные обозначения** — отдельные значки для силовой розетки, розетки с з/к, слаботочной точки,
выделенного вывода под конкретный прибор (подписывается прямо на плане).

**Типовые примечания** — назначение каждого нестандартного вывода текстом («вывод под встраиваемый
духовой шкаф», «вывод под тёплый пол, группа 1»), группа УЗО для мокрых зон.

**Частые ошибки**
- Розетка оказывается за мебелью «намертво» (не совпадает с планом расстановки мебели).
- Нет розетки под конкретную встраиваемую технику до заказа кухни/техники — вписывают потом
  штроблением по готовой отделке.
- Слаботочка не разведена отдельно от силовой (наводки, путаница при монтаже).

**Масштаб**: 1:50.

Источники: my-dom.design/plan-vykljuchatelej и topdom.ru (общий блок электрики),
dg-home.ru, remontkit.ru, elektro.ru, mebel169.ru, geometrium-school.ru/plan-elektriki,
energy-systems.ru. Примечание: цифры высот по кухне/технике подтверждены 2–3 источниками,
цифры по ТВ и «стандартной» розетке — расхождения, помечены как ориентир.

## 11. План сантехники

**Обязательные элементы**
- Точки подключения ХВС/ГВС и канализации по каждому сантехприбору с высотой оси/центра выпуска.
- Расположение стояков (водоснабжение, канализация, отопление) и коллекторного узла.
- Трапы (сифоны) для душевых зон/полов с указанием уклона к трапу.
- Привязка приборов (унитаз, раковина, ванна/душ, стиральная машина) к стенам.

**Размерные цепочки / привязки (ориентиры из источника, сверять с проектом инженера)**
- Водорозетки (выпуски ХВС/ГВС): высота 550–600 мм от пола, расстояние между выпусками 60–100 мм.
- Выпуск канализации: по оси примерно 380–420 мм от пола (для конкретного прибора уточняется
  по паспорту сантехники).
- Уклон труб канализации: Ø160 мм общий стояк — 1–1,5 см на метр; Ø110 мм (унитаз) — 1,5–2 см
  на метр; Ø50 мм (мойка/ванна/трап) — 2–3 см на метр.

**Условные обозначения** — по ГОСТ 21.601-79 (водопровод и канализация, рабочие чертежи):
свои значки для ХВС/ГВС/канализации, стояков, трапов, направления уклона.

**Типовые примечания** — «выводы сверить с моделью выбранной сантехники до монтажа», отметка
уровня чистого пола для санузла (часто ниже общего уровня квартиры на толщину гидроизоляции/стяжки).

**Частые ошибки**
- Высота выпуска не сверена с конкретной моделью смесителя/прибора — потом не совпадает с покупкой.
- Не заложен уклон к трапу — стоячая вода на полу душевой.
- Забыт вывод под стиральную/посудомоечную машину при перепланировке кухни/санузла.

**Масштаб**: 1:50.

Источники: dtepla.ru, ГОСТ 21.601-79 (vashdom.ru), topdom.ru, my-dom.design.

## 12. Развёртки стен

**Обязательные элементы**
- Фронтальная проекция каждой стены помещения (все 4 стены как отдельные развёртки, подряд по
  часовой стрелке или по схеме на плане-ключе).
- Маркировочный план-ключ на том же листе — откуда смотрит развёртка.
- Отделочные материалы по участкам стены (штриховка/заливка + подпись артикула).
- Дверные и оконные проёмы с размерами.
- Все электроточки, попадающие на стену (розетки, выключатели, светильники) — с высотной привязкой.
- Раскладка плитки там, где применимо (санузел, фартук) — на развёртке или отдельным листом
  (студии расходятся: часть держит раскладку на развёртке, часть — отдельным листом, чтобы
  не перегружать чертёж).
- Декоративные элементы, полки, ниши — с размерами и привязкой по высоте.
- 3D-вид для наглядности (частая практика, не строгая norma).

**Размерные цепочки / привязки**
- Общая длина стены + расстояния до проёмов от углов комнаты/координационных осей.
- Высотные отметки от уровня чистого пола (0.000): низ/верх проёмов, высота установки розеток/
  выключателей/светильников, верх мебели.
- Синий цвет — обычные размеры, красный — привязки розеток/выключателей и критичные размеры.

**Условные обозначения** — единая легенда штриховок/заливок материалов на всех развёртках альбома;
подписи материалов с артикулом прямо на развёртке.

**Типовые примечания** — «схема мебели на развёртке не является рабочим чертежом мебели» (детальные
размеры — в спецификации мебели отдельно).

**Частые ошибки**
- Не сверены высоты со светильниками/декором — бра упирается в молдинг или карниз.
- Асимметричная раскладка плитки относительно оси зеркала/раковины.
- Электроточки не совпадают с планом розеток/выключателей (разные листы — разные высоты).
- Слишком тёмная заливка стены — не читаются размерные линии и подписи.

**Масштаб**: 1:50 или 1:20 (для санузлов и мест с плиткой — чаще 1:20 ради читаемости раскладки).

Источники: geometrium-school.ru/razvertka-sten, gavrilova-bim-design.ru/pravila_sozdaniya_razvertok,
lineikadesign.ru/razvertki-pomeshcheniy, rybinska-design.com.

## 13. Раскладка плитки (санузлы, фартук)

**Обязательные элементы**
- Точная геометрия помещения/зоны с реальными размерами мебели и сантехники, наложенная на сетку
  плитки.
- Точка старта раскладки и направление швов.
- Артикул и формат плитки (по каждому виду/декору), размер шва.
- Схема организации гидроизоляционного порога и узел его примыкания (к наличнику двери, к сантехприбору).
- Расположение декоров/панно с центровкой относительно оси (зеркало, ниша).

**Размерные цепочки / привязки**
- Привязка старта раскладки — от видимого угла входа или от оси симметрии (раковина, ниша),
  чтобы избежать узких подрезок «на входе» и в углах.
- Ширина подрезки у кромок — контролируется расчётом, не должна быть меньше ~1/3 плитки
  (общее правило укладки, не встречается как жёсткая цифра во всех источниках — держится на практике
  мастеров).

**Условные обозначения** — сетка швов, направление затирки, обозначение декора/бордюра/панно
отдельным цветом.

**Типовые примечания** — «раскладка ориентировочная, точный расчёт количества — у прораба/поставщика»
(студии явно снимают с себя ответственность за точный подсчёт количества коробок).

**Частые ошибки**
- Узкие «огрызки» подрезки в видимых углах — раскладка не была отцентрирована.
- Панно/декор перекрыт зеркалом или шкафом — не сверили с планом мебели.
- Не показан узел примыкания порога душевой к дверному наличнику — рабочие делают по своему усмотрению.

**Масштаб**: 1:20 (иногда 1:10 для мелких зон типа фартука).

Источники: m.zems.pro/skhema-raskladki-plitki, antica.su (кабанчик), laparet.ru, plitz.ru.

## 14. План отделки стен и ведомость отделки

**Обязательные элементы плана**
- Зонирование стен по типу отделки (цветовая заливка/штриховка) с площадью по каждой зоне/помещению.
- Артикулы, коллекции, производители материалов — прямая ссылка на позицию в ведомости.

**Ведомость отделки — типовая структура таблицы**
Помещение / зона-поверхность (пол, стена, потолок) / материал и тип / производитель / коллекция /
точный артикул / цвет-тон-калибр / размер-формат / единица измерения / чистая площадь /
процент запаса / кратность упаковки / итого к заказу.

**Типовые примечания**
- Процент запаса материала — по категориям (у разных студий 5–15% в зависимости от материала
  и сложности раскладки — единого норматива в источниках нет, держится как вилка).
- Указание аналогов/заменителей на случай снятия позиции с производства.

**Частые ошибки**
- Ведомость не синхронизирована с планом/развёртками после правок проекта (частый разрыв
  «картинка одна — таблица другая»).
- Нет запаса на подрезку/бой — материала не хватает на объекте.
- Общие формулировки вместо артикула («смеситель для ванной» вместо модели) — по факту это ошибка
  скорее спецификации оборудования, но встречается и в ведомости отделки.

**Масштаб плана** — 1:50 (сама ведомость — табличный лист без масштаба).

Источники: forum.dwg.ru/showthread.php?t=19407, assistentus.ru, geometrium-school.ru/vedomost,
business.ru, blog.isakovadesign.ru.

## 15. Узлы и разрезы

**Обязательные элементы**
- Детальный разрез сложного места примыкания: короб ГКЛ, ниша со шторным карнизом, стык материалов
  пола (плитка/паркет), примыкание двери к облицованной стене, светодиодный профиль в нише.
- Все размеры узла — высоты, глубины, толщины слоёв («пирог» конструкции).
- Текстовые пояснения по материалам и креплению.

**Условные обозначения** — послойная штриховка материалов (ГОСТ 2.306-68: разные штриховки для
разных материалов — металл, дерево, ГКЛ, утеплитель).

**Типовые примечания** — ссылка на узел с основного плана/развёртки (номер узла в кружке-выноске),
требование согласовать узел с монтажником до начала работ на сложных местах.

**Частые ошибки**
- Узел не проработан для нестандартного примыкания — решение придумывает бригада на месте,
  результат отличается от визуализации.
- Не показан теневой профиль/шов между материалами — на объекте делают простой плинтус вместо
  задуманного «invisible»-примыкания.
- Отсутствует узел на переход уровня пола (порог) при разнице в 1–2 см — воспринимается на площадке
  как «неважно» и не выполняется.

**Масштаб**: 1:5, 1:10, 1:20 — по степени детализации узла (мельче для объёмных сечений короба,
крупнее для профилей/примыканий).

Источники: lagom-interior.com/nodes (каталог узлов, без методологии оформления), stroy-podskazka.ru,
blog.isakovadesign.ru, ГОСТ 2.306-68.

## 16. Спецификации, экспликация помещений, ведомость дверей

**Экспликация помещений — типовая структура**
Номер помещения / наименование / площадь / тип пола (материал) / высота потолка / примечание.
Обычно даётся отдельной таблицей на плане (не отдельным листом) и дублируется на титульном листе
или в пояснительной записке.

**Спецификация мебели — обязательные столбцы**
Наименование (полное, не обобщённое) / артикул / количество (с учётом запаса) / материал корпуса
(ЛДСП/МДФ/массив) / фурнитура (серия, направляющие) / внутренняя комплектация / механизмы
трансформации / ткань обивки (артикул + код чистки) / поставщик / цена за ед. и сумма / примечание.

**Спецификация светильников — обязательные столбцы**
Наименование / тип (подвесной/встроенный/трек/лента) / артикул / габариты и вес / материал /
тип источника света / световой поток (лм) / цветовая температура (K) / угол рассеивания /
IP-класс / совместимость с диммером/умным домом / поставщик / количество.

**Спецификация сантехники — обязательные столбцы**
Наименование / модель / способ установки (настенный/напольный/консольный) / габариты /
диаметр подводки / материал корпуса / наличие термостата / поставщик / количество.

**Ведомость дверей — типовая структура**
Позиция / тип (входная/межкомнатная/раздвижная/пустой проём) / размер проёма (Ш×В) /
сторона открывания (право/лево) / материал полотна (ГКЛ-короб под скрытую дверь, шпон МДФ/ЛДСП,
стекло) / фурнитура / примечание.

**Частые ошибки по всему блоку 16**
- Обобщённые описания вместо точного артикула («смеситель для ванной») — невозможно провести
  тендер среди поставщиков и проконтролировать подмену на площадке.
- Нет пересчёта количества с учётом запаса (материалы) или комплектности (мебель/фурнитура).
- Спецификация не согласована с чертежами после правок — на объекте расхождение «по проекту одно,
  по спецификации другое».
- Нет закладки образцов/паспортов изделий — споры при приёмке работ.

**Масштаб** — табличные листы без масштаба; при наличии графической части (пиктограммы) — под лист.

Источники: geometrium-school.ru/speczifikacziya, geometrium-school.ru/vedomost-otdelochnyh-materialov,
basicdecor.ru, rina-designer.ru (пример ведомости комплекта чертежей), sapr.ru (Revit-практика РФ).

| Тип листа | Рекомендуемый масштаб |
|---|---|
| Обмерный план, демонтаж, монтаж перегородок, мебель, полы, потолки, освещение, выключатели, розетки, сантехника | 1:50 (крупные объекты — 1:100) |
