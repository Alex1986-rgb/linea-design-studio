# Пакет «Проверка практиком» (31.10.2026)

Цель: живой проектировщик с опытом рабочей документации и стройки отвечает на один вопрос —
**«может ли прораб, электрик, сантехник, столяр и заказчик работать по этому альбому?»** — и пишет, где нет.
ИИ-критики (/qa в GOST-DRAFT) это уже делают, но отзыв 22.10 показал: зелёные проверки ≠ пригодный лист.

Статус: черновики. Ничего не отправлено. Письмо отправляет Александр сам, доступ к PDF даёт Александр сам.

## Состав пакета

| Файл | Что это |
|---|---|
| `pismo.md` | письмо-заявка практику: короткое (чат/личка) и полное (почта) |

| `forma-otveta.md` + `forma-otveta.csv` | форма ответа: таблица замечаний «лист / суть / серьёзность / как надо», итоговый вердикт |

## Что передаём практику

Альбом **prompt-kv54** (квартира 54 м² по брифу, «джапанди»), выпуск 30.10.2026, на Google Диске:
`gdrive:LINEA/Альбомы/2026-10-30 prompt-kv54/`

- PDF «студия» (выпуск для заказчика, 69 листов) — **главный объект проверки**;
- PDF полного альбома (101 лист / 113 стр.) — для сверки: там однолинейная схема щита, реестр открытых вопросов К-N;
- `vedomosti.xlsx` и DXF — по желанию практика.

**Ссылку не создаём**: доступ к папке даёт Александр сам (на почту/аккаунт практика), после согласия на условия.
Если папка на Диске названа иначе — Александр поправит путь в письме.

### Честно сказать практику заранее (иначе он потратит время на известное)

Приёмка критиками 30.10 (`~/projects/gost-draft-svod/docs/reviews/2026-10-30-kritiki-final.md`) уже нашла:
- **планировка условная**: обмера нет, план подобран по брифу (сумма помещений 64,00 м² при «54 м²»), стояки, мощность,
  материал стен приняты допущениями — на каждом листе стоит «ПРЕДВАРИТЕЛЬНО · не для производства работ»;
- в студии нет однолинейной схемы щита, тёплый пол не нарисован контуром, визуализаций нет (кадры не подписаны);
- масштаб на части листов студии не напечатан.

Просим не тратить замечания на это, а смотреть **формат и язык листов**: если бы основание было настоящим (обмер),
можно ли по таким листам работать. Это и есть вопрос пилота.

> Альтернатива (лучше): дождаться первого пилотного объекта с обмером и отдать практику его альбом. Тогда проверка
> отвечает и на формат, и на содержание. prompt-kv54 — для разовой экспертизы формата прямо сейчас.

## Порядок

1. Александр выбирает кандидата (`gde-nayti.md`) и формат (разовая экспертиза — для начала).
2. Отправляет письмо (`pismo.md`), договаривается о цене и сроке, даёт доступ к папке.
3. Практик заполняет `forma-otveta.csv` (или пишет как ему удобно — переносим в форму сами) + созвон 30–60 мин.
4. Ответ ложится в `~/projects/gost-draft-svod/docs/reviews/ГГГГ-ММ-ДД-praktik-<слаг>.md`, замечания раздаются владельцам
   по `knowledge/team.md`, закрываются по `knowledge/zakrytie-zamechanii.md` (`v-konveyere.md`).
5. Практик смотрит исправленное (повторная проверка — только его замечаний) и, если согласен, пишет «проверил» —
   только тогда его фамилия появляется в графе «Пров.».
