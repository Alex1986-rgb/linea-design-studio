# ИП и ЮKassa для LINEA — памятка по шагам

Не юридическая и не бухгалтерская консультация. Пункты с пометкой **[проверить]** — сверить с бухгалтером или юристом
до подачи. Порядок: ИП → счёт → ЮKassa (сначала тестовый магазин) → вписать данные в сайт и `config.php`.

## 1. Регистрация ИП (3–5 рабочих дней, госпошлины нет при подаче онлайн)
1. Госуслуги → «Регистрация ИП» или сайт ФНС → «Государственная регистрация ЮЛ и ИП» → форма Р21001 (нужна ЭЦП или подтверждённая учётка Госуслуг).
2. Коды ОКВЭД (основной — первый):
   - **71.11** — деятельность в области архитектуры (рабочая документация) — основной;
   - **74.10** — специализированная дизайнерская деятельность (дизайн-проекты интерьера);
   - для агентской части «Ремонт по проекту» (вознаграждение с бригад): **63.11** (обработка данных, площадки), **73.11** или **82.99** — **[проверить у бухгалтера]**, какой код точнее для агентского вознаграждения площадки;
   - по желанию **85.41** (обучение), **47.91** не нужен.
3. Сразу в том же заявлении — **переход на УСН «доходы» 6 %** (или отдельное уведомление в течение 30 дней после регистрации). **[проверить]** региональную ставку и порог НДС на УСН в 2026 году.
4. После регистрации: лист записи ЕГРИП (ОГРНИП) придёт на почту.

## 2. Расчётный счёт
Любой банк с бесплатным тарифом для ИП (Т-Банк, Точка, Модульбанк, Сбер). Нужны: БИК, корр. счёт, номер счёта — пригодятся в ЮKassa и в реквизитах на сайте.

## 3. ЮKassa — магазин LINEA на ИП
1. yookassa.ru → «Подключиться» → ИП, ИНН, сайт `https://дизайн-студия-квартир.рф`, вид деятельности — дизайн-проекты (услуги). **Отдельный магазин LINEA**, не ключи SeoMarket.
2. Сначала **тестовый магазин**: «Интеграция → Ключи API» → `shopId` и секрет `test_…`.
3. **Чеки 54-ФЗ:** подключить «Чеки от ЮKassa» (облачная касса, от ЮKassa — ОФД и ФН) **[проверить тариф на дату подключения]**. Система налогообложения в кабинете — УСН «доходы».
4. HTTP-уведомления: адрес `https://дизайн-студия-квартир.рф/api/pay-notify.php`, события `payment.succeeded`, `payment.canceled` (возвраты — `refund.succeeded`, обработка в коде ещё не сделана).
5. После проверки тестовым платежом — боевые ключи.
6. «Безопасная сделка» для бригад — **отдельный договор с ЮKassa**, не подключать без юриста.

## 4. Что вписать после регистрации
**Сайт — `tools/site-shell.js`:**
```js
const REQUISITES = { status: 'индивидуальный предприниматель', name: 'Кырлан Александр …', inn: '…', ogrnip: '…' };
const OFERTA_DRAFT = false;   // только после проверки текста оферты юристом
```
Потом пересобрать страницы (`gen-more-pages.js`, остальные генераторы, `sync-static-nav.js`, `touch-sitemap.js`) и выложить.

**Сервер — `~/dizain-studiya-kvartir/linea-private/config.php` (на Beget, не в git):**
```php
'mode' => 'yookassa',
'yk_shop_id' => '…', 'yk_secret' => '…',          // сначала test_…
'yk_receipt' => true, 'yk_vat_code' => 1,          // 1 = без НДС [проверить для УСН 2026]
'yk_tax_system' => 2,                              // 2 = УСН «доходы»
'notify_enabled' => true, 'notify_to' => '<ваша почта>', 'mail_from' => 'no-reply@<домен>',
'brig_requisites' => 'ИП …, ИНН …, р/с …, банк …, БИК …',   // для счетов бригадам
'base' => 'https://xn-----6kccjicviedfr1b2cbishm8w.xn--p1ai',
```
Листы вне сделки (2 500 ₽) включаются там же: `'brig_terms' => ['sheets_outside_paid' => true]` — только когда есть касса.
