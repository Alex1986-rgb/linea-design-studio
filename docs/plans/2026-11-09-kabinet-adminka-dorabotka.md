# Доработка кабинета клиента и админки (09.11.2026)

Основание: docs/reports/2026-11-09-kritik-kabinet-adminka.md. Каждая находка критика сначала проверена по коду.

1. **Письма клиенту.** Единый шаблон письма (HTML + текст, тема с номером, одна кнопка) в lib/brig-notify.php; функция kab_notify_order() = уведомление в кабинете + письмо с учётом prefs (группы, «сводка раз в день»). Исправить brief.php: письмо уходит и при account_id = 0 (клиент ещё не входил). События: бриф получен, сумма, счёт, оплата и старт, выпуск и вопросы, ответ на правки, сообщение студии, смена этапа.
2. **Сводка раз в день и вход.** Колонка notices.mail_state, дайджест в cron.php; вход: «выслать ещё раз через N с», запасной путь «напишите нам», если письма на сервере выключены.
3. **Данные заказа.** Миграция v9: orders.expected_at/expected_note, notices.mail_state. Терминал условий для сервера — site/… из TERMS (tools/gen-kabinet-page.js пишет server/api/lib/terms-client.json: ставка, минимум, круги правок, возврат, реквизиты).
4. **Кабинет.** Карточка оплаты с расшифровкой, плановая дата, единая история, вкладка «Бриф» (читаемо + догрузка файлов), К-N со сроком/«позже»/фото, счётчик правок, «что изменилось»; мобильная вёрстка (шаг N из 7, липкая кнопка только когда основная ушла с экрана).
5. **Админка.** Словарь вопросов брифа (tools/gen-brief-dict.js из brief-life.js → lib/brief-dict.json), читаемая вкладка «Бриф» с файлами; очередь «Ждут нас» на дашборде; список заказов с фильтрами/периодом/сортировкой/страницами; expected_at и кнопки этапов с видимым текстом письма.
6. **Мост в конвейер.** tools/order-pull.mjs и order-publish.mjs (только локальные пути).
7. **Проверки.** test-kabinety (новые разделы), снимки 1280/375, php -l, отчёт.
