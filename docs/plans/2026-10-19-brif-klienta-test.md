# План: бриф для первого тестового клиента — 19.10.2026

Запрос Александра: «закачай все проекты на сайт; завтра клиент будет создавать проект, пока бесплатно для теста — продумать,
доработать: надиктовать, добавить референсы и т. д.».

Сайт статический (GitHub Pages), сервера приёма нет — всё делается в браузере клиента.

1. Голос: кнопка микрофона у текстовых полей (Web Speech API, ru-RU) и отдельный шаг «Расскажите своими словами»;
   где распознавания нет — подсказка про микрофон на клавиатуре телефона.
2. Референсы: галерея визуализаций проектов студии («нравится / не нравится»), свои фото понравившихся интерьеров,
   ссылки (Pinterest и т. п.).
3. Дом: этажность, этаж у помещения, лестница, участок.
4. Отправка с файлами: архив ZIP в браузере (brief.json + план + фото, фото ужимаются до 1600 px); на телефоне —
   «Поделиться» (Web Share с файлами) прямо в WhatsApp / Telegram, на компьютере — скачивание; запасные каналы — письмо,
   копия текста.
5. Черновик сохраняется в браузере (localStorage), восстанавливается при возврате.
6. Приём на стороне студии: `tools/brief-intake.js <архив>` → `clients/<слаг>/` (brief.json, план, референсы) +
   памятка `docs/kb/priem-brifa.md` — как из брифа запустить проект в GOST-DRAFT.
7. Проверка в браузере (телефон / компьютер), выкладка, отчёт `docs/reports/2026-10-19-brif-klienta-test.md`.
