# 07.11.2026 — подача проектов «как у лучших»: сначала движок, проекты на паузе

Запрос Александра: у конкурентов проекты поданы красиво и со вкусом, у нас «как-то дёшево».
Новые проекты не делаем, пока не доработан движок. Плюс вопрос: сколько видов ремонта бывает.

## План
1. Разведка: 8–10 сильных студий (РФ + мир) — как устроена подача: обложка, концепция, мудборды,
   коллажи материалов, цветные планы, рендеры, типографика, вёрстка листа. Скриншоты-ориентиры
   для себя (не копируем). Плюс наша библиотека 216 альбомов (`design-reference-library`).
2. Разбор «дорого / дёшево»: список конкретных отличий нашей подачи от лучших (по листам).
3. Виды ремонта → в движок: класс ремонта (эконом / комфорт / бизнес / премиум) задаёт уровень
   мебели, материалов, декора и сметы; плюс состояние объекта (новостройка без отделки,
   white box, вторичка).
4. Доработка движка подачи по списку п. 2 (титул, концепция, мудборд, коллаж материалов,
   цветной план с мебелью, единая типографика).
5. Проверка на одном существующем проекте: до/после, критик-арт-директор «дорого/дёшево».
6. Отчёт + решение Александра, что берём дальше.
