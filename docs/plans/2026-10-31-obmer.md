# План 31.10.2026 — обмер квартиры как процесс студии

Цель: замерщик (или Александр с лазерной рулеткой) снимает квартиру за 1–1,5 часа, данные без перепечатывания попадают
в модель GOST-DRAFT (`object.survey` — событие с автором и датой, `rooms[]`, проёмы, стояки).

1. Формат `linea-survey/1` + пример `docs/obmer/survey-example.json` (чистые размеры, привязка помещений «за стеной»,
   проёмы от чистого угла, стояки/вентканалы/щит привязкой к двум стенам).
2. Конвертер `tools/survey-to-project.mjs`: survey.json → заготовка project.json по канону `gost-draft-svod/docs/schema.md`
   (оси стен, offset по сетке, контур, `object.survey`, `rooms[].survey`, реестр К-N на то, чего обмер не даёт).
   Проверка сборкой движка в scratchpad (дерево svod не трогать).
3. Протокол `docs/obmer/protokol.md`: порядок обхода, что мерить, точность, ошибки, чек-лист; нормы — только проверенные.
4. Печатный замерный лист A4 → `docs/obmer/zamernyj-list.pdf` (HTML + headless-браузер).
5. Форма для телефона `site/obmer/index.html` (каркас site-shell, noindex, вне sitemap): шаги по помещениям, черновик
   в localStorage, выгрузка survey.json, отправка на `server/api/survey.php` (https, test=1, linea-private/surveys).
   Проверка: `php -S 127.0.0.1` + браузер 375×812, на боевой ничего.
6. Оборудование и цены: `docs/obmer/oborudovanie-i-ceny.md` — веб-поиск, ссылки.
7. Отчёт `docs/reports/2026-10-31-obmer.md`, коммит явным `git add`, без push и без выкладки.
