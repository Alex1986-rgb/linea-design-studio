# 01.11.2026 — кабинет бригады (блок II) и связки с сайтом (блок III)

Спецификация — `docs/brigady/spec-kabinety-adminka.md` (разделы 2.5–2.6, 4, 4А, 5.12, 8 блоки II–III).

1. Схема v5: `br_members` (бригадир/сотрудник), `br_payments` (реестр оплат с подтверждением второй стороной, поля под Безопасную сделку),
   режим предложения «по разделам», аванс и план оплат, подписант ООО, согласие на публичную карточку, ответ на отзыв.
2. Ядро `server/api/lib/brigada.php`: роль в бригаде и права, «Сейчас от вас нужно», реестр оплат `brig_pay_*()`, документы, уведомления бригады.
3. API кабинета бригады `api/brigada.php?m=…` (модули из `api/brigade/*.php` перенесены в `lib/brigada/`, старые адреса — 307 на новый);
   новые модули: главная, команда, оплаты, документы, уведомления, рейтинг. Все смены статуса сделки — через `deal_transition()`.
4. Кабинет бригады `site/brigada/` на каркасе кабинета клиента: главная, заказы, объекты (договор, «Начать работу» с фото «до», мастер сдачи
   этапа, оплаты, листы), деньги, рейтинг, команда, профиль и документы, уведомления; нижняя панель на телефоне.
5. Кабинет клиента: модуль ремонта `kabinet-remont.js` — сравнение карточками, пошаговая приёмка, оплаты с подтверждением.
6. Панель: модерация анкет и файлов, пакеты и рассылка, разногласия, CSV-экспорт (защита от CSV-инъекций).
7. Сайт: «Войти» в шапке (site-shell → sync-static-nav), `BRIG_TERMS` из одного JSON для страниц и сервера + плашка расхождения, ссылки писем в кабинеты.
8. Тесты (SQLite + MariaDB), скриншоты 375/1280, пересборка страниц с пустым GOST_DRAFT, отчёт.
