## 1. Что уже хорошо

1. **Каркас и честность цифр.** Полный лендинг в верном порядке (герой → процесс → комплект → портфолио → тарифы → FAQ → контакты), все якоря работают; 74 листа = ровно 74 SVG, 11 визуализаций = 11 JPG, факты (56 м², джапанди, ЖК «Северный парк», тариф «Бизнес») сходятся на всех трёх страницах.
2. **Сильный hero и плотная воронка.** Оффер «за 48 часов» с числовыми пруфами, пара CTA «действие/доказательство», 7 консистентных точек входа на бриф.
3. **Демо-проект — редкий пруф.** 74 листа + 11 рендеров структурой реальной проектной документации (00 паспорт … 09 электрика), документы кликабельны (паспорт, ведомость, спецификация, смета HTML+CSV) — конкурент такого не показывает.
4. **SEO-фундамент главной.** Title/canonical/OG, schema ProfessionalService с офферами + FAQPage, robots+sitemap, lazy-load, лёгкие SVG, display=swap.
5. **Единая премиальная дизайн-система** index и brief: токены main.css, тёмная тема, Playfair+Inter, золото #C29A5B.
6. **UX брифа выше конкурентов:** 6 логичных шагов, предзаполненные комнаты, карточки стилей с палитрами, дефолт «на усмотрение студии», drag&drop, наводящие вопросы = квалификация лида; brief.json совпадает со схемой движка.
7. **FAQ бьёт в слабости remplanner** (развертки лишь в 1/8 проектов, нет сметы) и закрывает ключевые возражения; цены прозрачные, за м², с якорем «Популярный».

## 3. Добавить

### P0 — блокеры воронки и честности

| Что | Почему |
|---|---|
| Реальная отправка брифа (Web3Forms / Formspree / Telegram Bot API из brief.js) вместо mailto; mailto — скрытый fallback | Весь трафик упирается в неработающий последний шаг: mailto молча фейлится без почтового клиента |

| Чекбокс согласия ПДн + страница политики на шаге «Контакты» | Форма собирает имя/телефон/e-mail — без согласия нарушение 152-ФЗ |

## 4. Топ-5 действий прямо сейчас

1. **Починить приём заявок одним заходом:** Web3Forms или Telegram-бот в brief.js + валидация «телефон или e-mail обязательны» + финальный экран «Заявка отправлена» вместо JSON-дампа. Закрывает 4 P0 сразу; до этого весь остальной CRO бессмыслен — заявки физически не доходят.
2. **Демо-страница за один файл:** лого-ссылка на index, CTA «Заполнить бриф» в sticky-nav и после рендеров, head (title/description/canonical/OG), media query 1fr для мобильных. Пара десятков строк превращает тупик с горизонтальным скроллом в конверсионную страницу.
3. **Снять противоречие тарифов:** решить, входят ли визуализации в «Бизнес», и поправить 2–4 строки текста (hero, #kit, тариф «Премиум», подпись демо). Минута работы, убирает риск конфликта с клиентом на кассе.
4. **Реальные каналы связи:** Telegram/WhatsApp в шапке, контактах и финале брифа, убрать фейковый hello@linea.studio, добавить чекбокс ПДн + политику. Без этого со «студией» невозможно связаться в принципе.
5. **Перегенерировать демо движком с подписями:** manifest человеческих названий листов в engine/generate.js → alt + figcaption по шаблону «Обмерный план гостиной-кухни — квартира 56 м², ЖК Северный парк». Одна правка генератора чинит 74 alt, слаги-подписи и SEO-актив картиночной выдачи (правка строго через движок — по CLAUDE.md проекта).
