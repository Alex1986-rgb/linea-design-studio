# Задача: создай профессиональный комплект рабочих чертежей квартиры по ГОСТ/СПДС

## Роли и порядок

1. **interior-designer** — планировочное решение, ведомость отделки, спецификация мебели, задания смежникам.
2. **chief-engineer** — допуск решения: несущие, перепланировка, мокрые зоны, общедомовые сети.
3. **electrical-engineer** и **plumbing-engineer** — параллельно: ЭОМ и ВК/ОВ по утверждённой планировке.
4. **draftsman** — состав листов, оформление, реализация через движок, машинные проверки.
5. **estimator** — объёмы от чертежа, спецификация, смета.
6. **normcontrol** — реестр замечаний → возврат к draftsman / автору раздела → повторная проверка.
7. **chief-engineer** — финальная подпись «к выдаче».

Каждая следующая роль получает на вход полный выход предыдущей (раздел «Результат» + «Передача»).

## Входные данные

```
Объект:             {{ТИП: квартира | апартаменты}}, {{АДРЕС / ЖК}}, дом {{ТИП_ДОМА: монолит | панель | кирпич}}
Площадь:            {{ПЛОЩАДЬ_М2}} м², высота потолка {{ВЫСОТА_М}} м, этаж {{ЭТАЖ}}
Бриф:               {{ПУТЬ_К_BRIEF_JSON}}  (схема examples/demo-brief.json: размеры в метрах, стены A/B/C/D = верх/право/низ/лево)
Обмер:              {{ОБМЕРНЫЙ_ПЛАН | ФОТО | ПЛАН_БТИ}}
Конструктив:        несущие {{object.bearing[]}}, стояки {{object.risers[]}}, вентканалы {{ВЕНТКАНАЛЫ}}
Семья и сценарии:   {{СОСТАВ_СЕМЬИ, ПРИВЫЧКИ, ХРАНЕНИЕ, ТЕХНИКА}}
Стиль и тариф:      {{СТИЛЬ из engine/presets.js}}, тариф {{ЭКОНОМ | БИЗНЕС | ПРЕМИУМ}}

Дата выпуска:       {{ДД.ММ.ГГГГ}}  (для воспроизводимости: --date)
```

## Что сделать

1. Нормализовать бриф; прогнать `engine/validate.js`; ошибки брифа — в «Вопросы» клиенту, не додумывать.
2. Разработать планировочное решение и проверить проходы по СП 31-107-2004, 6.1.12.
3. Получить допуск ГИПа по каждому изменению (реестр изменений).
4. Выпустить ЭОМ (зоны ПУЭ, точки с привязками, группы, щит, кабельный журнал, ТП) и ВК/ОВ (водорозетки, выпуски, уклоны 1/d, гидроизоляция, люки, кондиционер).
5. Сформировать альбом:
   титул с перечнем → презентационный план → обмерный + экспликация → демонтаж → монтаж → планировка + спецификация →
   двери + ведомость проёмов → розетки и выводы → потолки → освещение → выключатели → схема групп → полы + экспликация (форма 4) →
   отделка стен + ведомость → тёплые полы → кондиционирование → сантехника → щит и кабельный журнал → обозначение развёрток →
   развёртки всех стен → разрезы 1—1, 2—2 → узлы А–Д.
6. Генерация: `node engine/generate.js {{brief}} {{outdir}} --date={{ДАТА}} --strict`; ч/б версия при необходимости `--mono`.
7. Проверки: `tools/audit-sheets.js`, `tools/lint-sheets.js`, `tools/check-sheets.js`, `tools/regen-fixtures.js` (если менялся движок); единый PDF `./tools/album.sh {{outdir}}`.
8. Смета и спецификация от чертежа; контрольные суммы.
9. Нормоконтроль → исправления → повтор до 0 блокеров.

## Формат выхода

```
## Итог — листов N, пакет, блокеров 0/N, что осталось
## Ведомость рабочих чертежей — № | наименование | тип | масштаб
## Реестр изменений ГИПа — изменение | тип работ | решение | условие
## Ключевые таблицы — ведомость отделки, спецификация мебели, ведомость точек ЭОМ, ведомость точек ВК, кабельный журнал
## Смета — итоги по разделам; контрольные суммы
## Нормоконтроль — вердикт и открытые замечания
## Файлы — папка выпуска, album.pdf, presentation.html, index.html
## Вопросы клиенту / Допущения
```

## Критерии приёмки

- 0 блокеров нормоконтроля; audit/lint/check чистые.
- Каждая розетка, выключатель, водорозетка и выпуск имеют привязку и высоту от чистого пола.
- Масштаб в штампе = геометрии; «Лист N из M» верно; нумерация сквозная.
- Числа сходятся: план ↔ развёртка ↔ ведомость ↔ смета.
- В общих указаниях: отметка 0,000 = чистый пол; расчёты — по проектам ЭОМ/ВК/ОВ организаций с допуском; несущие — только по проекту КР.
