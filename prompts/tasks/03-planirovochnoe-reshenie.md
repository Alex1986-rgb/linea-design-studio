# Задача: разработай планировочное решение по обмерному плану

## Роли и порядок

1. **interior-designer** — анализ, 2–3 варианта зонирования, выбранный вариант с расстановкой.
2. **chief-engineer** — допуск каждого изменения стен и мокрых зон; условия.
3. **interior-designer** — доработка по условиям ГИПа.
4. **draftsman** — оформление листа «Планировочное решение» + спецификация позиций (и при необходимости демонтаж/монтаж).
5. **normcontrol** (экспресс) — проходы, двери, обозначения, согласованность со спецификацией.

## Входные данные

```
Обмерный план:     {{ФАЙЛ / ОПИСАНИЕ: габариты помещений, толщины стен, проёмы с привязками и высотами}}
Конструктив:       тип дома {{ТИП}}, несущие {{СПИСОК_СТЕН или «неизвестно»}}, стояки {{КООРДИНАТЫ, Ø}}, вентканалы {{КООРДИНАТЫ}}
Окна и радиаторы:  {{ПОЛОЖЕНИЕ, ВЫСОТА ПОДОКОННИКА}}
Семья:             {{КТО ЖИВЁТ, ВОЗРАСТ, РАБОТА ДОМА, ГОСТИ, ЖИВОТНЫЕ}}
Помещения-желания: {{СПАЛЕН N, КАБИНЕТ, ГАРДЕРОБНАЯ, ПОСТИРОЧНАЯ, ВАННА/ДУШ, …}}
Хранение:          {{ПОГОННЫЕ МЕТРЫ или «по составу семьи»}}
Кухня:             {{ТИП: линейная | угловая | П | остров}}, техника {{СПИСОК}}, плита {{ЭЛЕКТРО | ГАЗ}}
Ограничения:       {{что нельзя трогать; бюджет перепланировки; нужна ли согласуемость}}
Стиль:             {{СТИЛЬ}}
```

## Что сделать

1. Нанести ограничения: несущие (неизвестно = несущая), стояки, вентканалы, окна, радиаторы, щит, газ.
2. Составить 2–3 варианта зонирования (схема + таблица помещений с площадями) и сравнить по: свет, проходы, хранение, объём перепланировки, согласуемость.
3. Для выбранного — расстановка мебели реальными габаритами; проверка проходов по СП 31-107-2004, 6.1.12; зоны открывания дверей и окон.
4. Мокрые зоны — только над нежилыми соседей и не за счёт жилых комнат; расстояние приборов до стояка с учётом уклона Ø110 (1/d = 0,010).
5. Передать ГИПу реестр изменений; доработать по условиям.
6. Выпустить лист и спецификацию позиций; задания смежникам (электрика, сантехника, климат).

## Формат выхода

```
## Итог — выбранный вариант, ключевые компромиссы, нужна ли согласованная перепланировка
## Сравнение вариантов — критерий | вариант 1 | вариант 2 | вариант 3
## Экспликация — № | помещение | площадь, м² | было/стало
## Расстановка — поз. | наименование | Ш×Г×В, мм | помещение | привязка от стен, мм
## Проходы — место | факт, мм | норма/практика | статус
## Реестр изменений и решение ГИПа — изменение | тип работ | решение | условие
## Задания смежникам
## Вопросы / Допущения
```

## Критерии приёмки

- Все нормируемые проходы соблюдены или отступление обосновано и помечено.
- Нет демонтажа несущих без условия «по техзаключению».
- Двери не бьют в мебель; выключатели не за полотном; окна открываются.
- Σ площадей помещений = площадь по обмеру ± 2 %.
