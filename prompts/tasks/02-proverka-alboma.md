# Задача: проверь альбом на соответствие нормам

## Роли и порядок

1. **normcontrol** — ведущая роль: машинные проверки + ручной нормоконтроль оформления и содержания.
2. **electrical-engineer** — углублённая проверка листов ЭОМ (зоны, УЗО, группы, выводы, привязки) — если в альбоме есть электрика.
3. **plumbing-engineer** — углублённая проверка ВК/ОВ (высоты, уклоны, гидроизоляция, люки).
4. **chief-engineer** — несущие, перепланировка, мокрые зоны, сквозная увязка; сводит всё в вердикт.

Роли 2–3 можно запускать параллельно; их замечания передаются нормоконтролёру для единого реестра.

## Входные данные

```
Альбом:          {{ПАПКА_ПРОЕКТА}} или {{ПУТЬ_К_PDF}}
Бриф:            {{ПУТЬ_К_BRIEF_JSON}} (если есть)
Тип объекта:     {{квартира в МКД | дом | участок}}
Глубина:         {{экспресс: только блокеры | полная}}
Листы:           {{все | перечень типов: sockets, plumbing, elevation, …}}
Чужой альбом:    {{да — не LINEA, машинные проверки недоступны | нет}}
```

## Что сделать

1. Для альбома LINEA: `node tools/audit-sheets.js {{папка}}`, `node tools/lint-sheets.js {{папка}}`, `node tools/check-sheets.js {{папка}}`; ошибки брифа — из `manifest.json` / `00-pasport/zamechaniya.html`.
2. Для стороннего альбома: ручная проверка по тем же пунктам; комплектность — по составу марки АИ.
3. Проверить оформление: комплектность и нумерация, штамп, масштаб = геометрия, линии и шрифты, размеры (засечки, замкнутые цепочки), отметки, выноски, обозначения ГОСТ 21.201 / 21.205 / 21.210 / 21.608.
4. Проверить содержание: зоны ванной и УЗО (ПУЭ гл. 7.1), высоты (ПУЭ 6.6.30–6.6.31), газ (ПУЭ 7.1.50), проходы (СП 31-107-2004, 6.1.12), пол санузла и гидроизоляция (СП 29.13330.2011), уклоны 1/d (СП 30.13330.2020), высоты приборов (СП 73.13330), несущие и перепланировка (ЖК РФ, ПП Госстроя № 170).
5. Сквозная сверка: одна точка — одна привязка на всех листах; количества план ↔ ведомость ↔ смета; отметки потолков и полов на всех листах.
6. Каждое замечание классифицировать: блокер / важно / рекомендация; пометить [Н] / [П] / [Р].

## Формат выхода

```
## Вердикт — выдавать / после исправлений / не выдавать; блокеров N, важных N, рекомендаций N
## Машинные проверки — итоги
## Реестр замечаний — № | уровень | лист | элемент | что не так | основание | как исправить | точка правки
## Сквозные расхождения — величина | лист А | лист Б | верное значение
## Инженерные условия ГИПа — что требует техзаключения, согласования, проекта организации с допуском
## Что проверить после исправления
```

## Критерии качества проверки

- Ни одного замечания без адреса (лист + элемент) и без способа исправления.
- Ни одной нормы без документа; пункт — только если известен точно.
- Практика не выдана за норму; отменённые СНиП не использованы как основание.
- Блокеры идут первыми.
