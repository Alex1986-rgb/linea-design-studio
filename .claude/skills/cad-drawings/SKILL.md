# Канон рабочих чертежей LINEA

Стандарт снят с рабочих альбомов практикующих студий (разбор 8 альбомов, 13 листов детально — см. `docs/research-remplanner.md`, `docs/cad-styleguide.md`, `docs/parity-report.md`) и адаптирован под наш SVG-генератор. Всё, что здесь написано, — правила, а не пожелания: лист, нарушающий их, переделывается.

**Железное правило проекта:** чертёж правится ТОЛЬКО через код `engine/generate.js` + перегенерация. Руками в SVG — никогда.

## 1. Состав альбома

Ядро (порядок не меняется — по нему подрядчик читает проект):

| # | Лист | Обязателен |
|---|---|---|
| 1 | Обмерный план | да |
| 2 | План демонтажа | да |
| 3 | План монтажа конструкций | да |
| 4 | Планировочное решение (мебель) | да |
| 5 | Экспликация помещений + ведомость дверей Дn | да |
| 6 | Розетки и силовые выводы | да |
| 7 | План потолков | да |
| 8 | План освещения (отдельно от розеток — всегда) | да |
| 9 | План выключателей | да |
| 10 | Напольные покрытия + ведомость м²/п.м. | да |
| 11 | Отделка стен | да |
| 12 | Тёплые полы | да |
| 13 | Кондиционирование с трассами дренажа | желательно |

Наша отстройка (у большинства студий этого нет — не убирать): развертки каждой стены, потолки 2–3 уровня с узлом М 1:20, раскладка плитки, спецификация с артикулами, смета, фото реализации на листах.

Порядок разделов в папке: `00-pasport` → `01-kvartira` (сводные) → `01-obmer` → `02-plany` → `03-poly` → `04-razvertki` → `05-potolki` → `06-koncept` → `07-materialy` → `08-smeta` → `09-elektrika`.

Визуализации идут **после** чертежей, не вперемешку.

## 2. Анатомия листа

- **Формат:** А3 альбомный, 420×297 мм (в коде `PAGE = {w:1587, h:1123}` при 96 dpi). Один формат на весь альбом — разнокалиберные холсты запрещены.
- **Рамка:** по контуру поля, поле подшивки слева 20 мм (`PAGE.ml = 76`).
- **Масштаб:** только из ряда 1:20 / 1:25 / 1:50 / 1:75 / 1:100 / 1:150 / 1:200. Подбирается автоматически (`SCALE_SERIES` в `svgDoc`) и печатается в штампе. **Масштаб в штампе обязан совпадать с фактическим** — иначе размер, снятый линейкой, врёт.
- **Контрольный отрезок** 1000 мм в левом нижнем углу + подпись «печать 1:1, без подгонки под лист».
- **Штамп** — единый для всех листов, правый нижний угол, рисуется рамкой листа (`sheetStampBlock`), а не содержимым. Графы: студия · объект (адрес, площадь, стиль) · наименование листа · стадия РП · масштаб · лист N из M · дата.
- **Зоны листа:** заголовок и подзаголовок сверху → поле чертежа слева/по центру → правая колонка: условные обозначения, затем таблицы и ведомости → нумерованные «Примечания:» снизу → штамп.
- Ориентация плана **одинакова на всех листах альбома**. Никогда не поворачивать план от листа к листу.

## 3. Слои: одна подложка — много слоёв

Главный принцип. Один и тот же план перерисовывается на каждом листе, меняется только активный слой:

- подложка (стены, мебель, сантехника) — приглушённая, тонкая;
- активный слой листа — **единственный акцент** на листе;
- на каждом листе — своя легенда только для своего слоя.

Никогда не мешать два активных слоя на одном листе (розетки и свет — всегда разные листы).

## 4. Графика

Палитра — `CAD` в `engine/generate.js`:

| Элемент | Правило |
|---|---|
| Стены | серая заливка в реальную толщину + тонкий тёмный контур |
| Наружные стены | та же заливка + штриховка 45°, клипованная контуром |
| Новые перегородки | отдельный цвет + косая штриховка |
| Демонтаж | красный, только он; красный на техническом листе больше ничем не занят |
| Мебель | зелёный контур, без заливки, с деталировкой (подушки, спинка, штанга, чаша) |
| Окна | прорезь в стене + линия остекления + линия подоконника; радиатор под окном обязателен |
| Двери | полотно + четверть-дуга открывания, дуга никогда не заливается |
| Свет | люстра — крупный круг, спот — малый, LED — пунктир |
| Розетки | «купол» на ножке; заливка/двойной контур = IP44; TV/LAN — своя метка |

Требование читаемости: различие между слоями должно сохраняться **в ч/б** — дублировать цвет типом штриха (dash-код), штриховкой или буквенным маркером.

## 5. Размеры

- Единица одна на весь альбом — миллиметры. Число без суффикса; единица объявлена в примечаниях.
- Засечки — «птички» 45°, не стрелки. Стрелка только на линии-выноске.
- **Минимум два яруса** снаружи: первый — проёмы и простенки, второй — габарит. Сумма сегментов обязана сходиться с габаритом (проверять!).
- Внутри помещений — цепочки привязок мебели (проекции предметов на оси X и Y).
- Электрика — привязка **L/H**: расстояние до ближайшей стены / высота установки от чистого пола.
- Проёмы — записью **ширина/высота**.
- Текст размера над линией по центру, вертикальный повёрнут на 90°, под цифрой белая подложка поверх заливок.
- Оговорка «без учёта отделочного слоя» — на обмерном плане обязательна.

## 6. Условные обозначения

Правило-инвариант: **символ в легенде рисуется тем же кодом, что символ на плане**. Расхождение легенды и плана — брак листа.

Размер символа задаётся в единицах листа (мм бумаги), а не в единицах модели: символ розетки одинаков на плане квартиры 1:100 и на плане комнаты 1:50.

## 7. Примечания

Нумерованный список внизу слева, мелким кеглем. Собирается по условиям проекта, а не копируется. Обязательный минимум:

1. Единицы и база отсчёта («все размеры в мм», «за 0,000 принят уровень чистового пола»).
2. «Размеры проверять по месту» + допуск.
3. Специфика листа: гидроизоляция для полов санузла, УЗО и IP44 для электрики, закладные для потолков, стыки покрытий на оси дверного полотна.

Критичное выделяется красной рамкой — но не более одного такого блока на лист.

## 8. Чек-лист приёмки листа

Перед тем как считать лист готовым:

- [ ] А3, рамка, поле подшивки, штамп с верным номером и масштабом
- [ ] Масштаб в штампе = фактическому
- [ ] Сумма размерных сегментов = габариту
- [ ] Нет текста, обрезанного краем листа или рамкой
- [ ] Нет наложения подписей друг на друга и на символы
- [ ] Мебель/конструкции не стоят в зоне открывания дверей
- [ ] Легенда покрывает все символы листа и совпадает с ними
- [ ] Есть примечания, единицы объявлены
- [ ] Лист читается в ч/б

Регрессии ловятся прогоном: перегенерировать демо, растеризовать листы, просмотреть глазами (или агентами) — см. `/qa-project`.

## 9. Как добавлять новый тип листа

1. Функция `drawXxx(room, sheet)` для покомнатного или `drawFlatXxx(sheetNo)` через `flatSheet()` для сводного.
2. Внутри: подложка (`roomWalls`/`flatLayer`) → активный слой → легенда (`flatLegendBox`) → примечания.
3. Вызвать `stamp(...)`/`flatStamp(...)` — они не рисуют, а передают данные штампу листа.
4. Зарегистрировать через `sheetOut(путь, maker, 'Наименование', масштаб)` — попадёт в ведомость и просмотрщик.
5. Обновить состав в паспорте и раздел в `viewerHTML`.
6. Перегенерировать демо и проверить по чек-листу выше.
