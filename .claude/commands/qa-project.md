---
description: Приёмка готовой папки проекта главным архитектором (QA)
---

Запусти субагента **chief-architect** для приёмки папки проекта. Вход: $ARGUMENTS (slug клиента или путь к папке project; пусто = site/portfolio/demo).

После приёмки покажи вердикт и, при возврате, план исправлений по агентам.
