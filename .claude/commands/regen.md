description: Перегенерация проекта или обоих демо + три выпускные проверки
---

Перегенерировать папку проекта и проверить результат. Вход: $ARGUMENTS (slug клиента, путь к brief.json; пусто = оба демо).

1. **Пусто** — перегенерируй оба демо:
   - `node engine/generate.js examples/demo-brief.json site/portfolio/demo`
   - `node engine/generate.js examples/house-brief.json site/portfolio/dom-120`
   Иначе: `node engine/generate.js clients/<slug>/brief.json clients/<slug>/project --strict` (при ошибках брифа движок остановится — покажи их пользователю и не продолжай).
2. Три проверки по каждой перегенерированной папке, все обязаны быть чистыми:
   - `node tools/audit-sheets.js <папка>` — 0 нарушений канона;
   - `node tools/lint-sheets.js <папка>` — 0 листов с мелким кеглем или тонким пером;
   - `node tools/regen-fixtures.js` — покажи, какие фикстуры изменились.
3. Сверь числа: «Листов N» в штампе = числу листов в ведомости (движок предупреждает в консоли при расхождении); площади в паспорте = сумме по экспликации.
4. Если фикстуры изменились и это задумано — `node tools/regen-fixtures.js --update`, иначе разберись, что поехало.
5. Покажи итог: путь, число листов и файлов, итог сметы, результаты трёх проверок числами, что изменилось против эталона.

Не трогай SVG руками ни при каких обстоятельствах — только движок и перегенерация.
